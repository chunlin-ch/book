# 知识点概述
正态随机向量的线性变换是多元正态分布最核心、最根本的性质。它指出，对一个服从多元正态分布的随机向量进行任意的线性变换（矩阵乘法加向量平移），得到的新随机向量**仍然服从多元正态分布**。这个性质保证了正态分布家族在线性运算下的封闭性，是其在理论和应用中占据核心地位的根本原因。

# 详细解释

### 1. 定理内容

设 $\mathbf{X}$ 是一个n维正态随机向量，其分布为：
$$\mathbf{X} \sim N(\mathbf{\mu}, \mathbf{\Sigma})$$

定义一个新的m维随机向量 $\mathbf{Y}$，它是 $\mathbf{X}$ 的线性变换：
$$\mathbf{Y} = \mathbf{A}\mathbf{X} + \mathbf{b}$$

其中：
*   $\mathbf{A}$ 是一个 $m \times n$ 的常数矩阵。
*   $\mathbf{b}$ 是一个 $m \times 1$ 的常数向量。

那么，**$\\mathbf{Y}$ 也服从多元正态分布**，其均值向量和协方差矩阵为：

*   **新的均值向量**: $E(\mathbf{Y}) = \mathbf{A}\mathbf{\mu} + \mathbf{b}$
*   **新的协方差矩阵**: $D(\mathbf{Y}) = \mathbf{A}\mathbf{\Sigma}\mathbf{A}^T$

即：
$$\mathbf{Y} \sim N(\mathbf{A}\mathbf{\mu} + \mathbf{b}, \mathbf{A}\mathbf{\Sigma}\mathbf{A}^T)$$

### 2. 参数变换的推导

*   **均值向量的推导**: 利用期望的线性性质。
    $E(\mathbf{Y}) = E(\mathbf{A}\mathbf{X} + \mathbf{b}) = E(\mathbf{A}\mathbf{X}) + E(\mathbf{b}) = \mathbf{A}E(\mathbf{X}) + \mathbf{b} = \mathbf{A}\mathbf{\mu} + \mathbf{b}$。

*   **协方差矩阵的推导**: 利用协方差矩阵的性质。
    $D(\mathbf{Y}) = D(\mathbf{A}\mathbf{X} + \mathbf{b}) = D(\mathbf{A}\mathbf{X})$ (平移不影响协方差)。
    根据协方差矩阵的线性变换性质，可得 $D(\mathbf{A}\mathbf{X}) = \mathbf{A} D(\mathbf{X}) \mathbf{A}^T = \mathbf{A}\mathbf{\Sigma}\mathbf{A}^T$。

### 3. 重要特例与应用

*   **任意线性组合是一维正态分布**: 
    这是多元正态分布的等价定义。如果我们取 $m=1$，那么 $\mathbf{A}$ 就是一个 $1 \times n$ 的行向量，记为 $\mathbf{a}^T = (a_1, \dots, a_n)$，$\mathbf{b}$ 是一个标量0。那么 $Y = \mathbf{a}^T\mathbf{X} = \sum a_i X_i$ 就是一个一维随机变量。根据定理， $Y$ 服从一维正态分布，其均值为 $\mathbf{a}^T\mathbf{\mu}$，方差为 $\mathbf{a}^T\mathbf{\Sigma}\mathbf{a}$。

*   **边缘分布是正态分布**: 
    如果我们想求子向量（例如前k个分量）的分布，可以构造一个选择矩阵 $\mathbf{A}$（例如，前k行为单位矩阵的对应块，其余为0），通过线性变换 $\mathbf{Y} = \mathbf{A}\mathbf{X}$ 提取出子向量。根据定理，这个子向量仍然服从多元正态分布。

*   **正交变换与独立性**: 
    在主成分分析（PCA）中，我们寻找一个特殊的正交矩阵 $\mathbf{P}$，对中心化的随机向量 $\mathbf{X}-\mathbf{\mu}$ 进行线性变换 $\mathbf{Y} = \mathbf{P}^T(\mathbf{X}-\mathbf{\mu})$。这个变换的目标是使得新的协方差矩阵 $\mathbf{P}^T\mathbf{\Sigma}\mathbf{P}$ 成为一个**对角矩阵**。由于新的协方差矩阵非对角元全为0，这意味着新的随机向量 $\mathbf{Y}$ 的所有分量都是**相互独立**的。这实现了从相关的多维数据中提取出不相关的（对于正态分布即独立的）主成分。

# 学习要点
*   **记住公式**: 必须牢记线性变换后新的均值向量和协方差矩阵的计算公式：$\\mathbf{\mu}_Y = \mathbf{A}\mathbf{\mu}_X+\mathbf{b}$ 和 $\\mathbf{\Sigma}_Y = \mathbf{A}\mathbf{\Sigma}_X \mathbf{A}^T$。注意协方差矩阵变换中 $\\mathbf{A}$ 和其转置 $\\mathbf{A}^T$ 的位置。
*   **理解本质**: 理解这个性质是正态分布“家族”保持其特征（正态性）的关键。无论如何对正态向量进行“拉伸”、“旋转”、“平移”（即线性变换），它仍然是正态家族的一员。
*   **应用广泛**: 认识到这个性质是许多高级统计方法（如因子分析、主成分分析、卡尔曼滤波）的理论基础。
