# 知识点概述

随机试验是用于研究随机现象的、满足特定条件的“试验”。其核心特征是：试验结果不确定，但所有可能的结果集合是已知的。

# 教材原文

> 进行一次试验，如果其所得结果不能完全预言，但其全体可能结果是已知的，则称此试验为随机试验。这里及今后所使用的“试验”这一术语，其含义是广泛的。它既可以是通常意义下的物理或化学的实验，也可以是对自然或社会现象的观测与记录。

# 详细解释

- **背景和动机**: 为了能用数学方法研究随机现象，需要对观察和实验的过程进行抽象和规范化，从而引出了随机试验的概念。
- **核心原理/特征**:
    1.  **结果不确定性**: 在试验之前，无法预知哪一个结果会发生。
    2.  **所有可能结果可知**: 试验的所有可能结果构成一个明确的集合，即样本空间。
    3.  **可重复性**: 试验可以在相同或相似的条件下重复进行（这更多是古典概率和频率学派的要求，公理化体系中不作强制要求，但有助于理解）。

# 学习要点

- **掌握随机试验的两个核心特征**: 结果的随机性和所有可能结果的可知性。
- **区分随机试验与普通实验**: 普通实验在确定条件下结果是确定的，而随机试验结果不确定。

# 实践应用

- **抛一枚硬币**: 结果是“正面”或“反面”，结果不确定，但所有可能结果已知。
- **记录一小时内某电话的呼叫次数**: 结果是0, 1, 2, ...中的一个，具体次数不确定，但可能结果的集合是所有非负整数。
- **从一批产品中抽检一件**: 结果是“合格品”或“次品”，结果不确定，但所有可能结果已知。
