# 知识点概述

对偶性（Duality）是优化理论中的一个深刻而优美的概念。它为每一个原始优化问题（Primal Problem）都关联了一个对偶问题（Dual Problem）。对偶问题的解为原始问题提供了一个下界，并且在某些条件下（特别是凸优化），对偶问题的解与原始问题的解紧密相关，两者之间没有间隙。对偶理论不仅为算法设计（如增广拉格朗日法、内点法）提供了基础，也为问题的敏感性分析和某些问题的简化求解提供了工具。

# 教材原文

> We define the dual objective function $q: \mathbb{R}^m \to \mathbb{R}$ as follows:
> $$q(\lambda) = \inf_x \mathcal{L}(x, \lambda). \tag{12.82}$$
> The dual problem to (12.81) is defined as follows:
> $$\max_{\lambda \in \mathbb{R}^m} q(\lambda) \quad \text{subject to } \lambda \geq 0. \tag{12.84}$$
> **Theorem 12.11 (Weak Duality).**
> For any $\bar{x}$ feasible for (12.81) and any $\bar{\lambda} \geq 0$, we have $q(\bar{\lambda}) \leq f(\bar{x})$.

# 详细解释

（为简化，本节主要讨论只有不等式约束的凸优化问题：$\\min f(x)$ s.t. $c(x) \geq 0$）

1.  **拉格朗日对偶函数 (Lagrangian Dual Function)**
    *   首先定义拉格朗日函数: $\mathcal{L}(x, \lambda) = f(x) - \lambda^T c(x)$。
    *   对偶函数 $q(\lambda)$ 定义为拉格朗日函数关于原始变量$x$的**全局下确界 (infimum)**：
        $$q(\lambda) = \inf_x \mathcal{L}(x, \lambda)$$
    *   **重要性质**: 无论原始问题是否为凸，对偶函数$q(\lambda)$永远是一个**凹函数**。这是一个非常好的性质，因为求解一个凹函数的最大化问题（等价于凸函数的最小化）相对容易。

2.  **对偶问题 (The Dual Problem)**
    *   对偶问题就是最大化对偶函数$q(\lambda)$，同时要求拉格朗日乘子$\\lambda$满足非负性（对应于原始问题的不等式约束 $c_i(x) \geq 0$）。
        $$\\max_{\\lambda} q(\lambda) \quad \text{s.t. } \lambda \geq 0$$

3.  **弱对偶性 (Weak Duality)**
    *   **定理**: 对偶问题的任何可行解$q(\lambda)$（其中$\\lambda \geq 0$）都是原始问题最优值$f(x^*)$的一个**下界**。即 $q(\lambda) \leq f(x^*)$。
    *   **证明**: $q(\lambda) = \inf_x \mathcal{L}(x, \lambda) \leq \mathcal{L}(x^*, \lambda) = f(x^*) - \lambda^T c(x^*) \leq f(x^*)$。（因为$\\lambda \geq 0$且$c(x^*) \geq 0$）
    *   **对偶间隙 (Duality Gap)**: $f(x^*) - q(\lambda^*)$ 的差值被称为对偶间隙。弱对偶性表明这个间隙总是非负的。

4.  **强对偶性 (Strong Duality)**
    *   **定义**: 如果对偶间隙为零，即原始问题的最优值与对偶问题的最优值相等（$f(x^*) = q(\lambda^*)$），则称强对偶性成立。
    *   **条件**: 强对偶性不是对所有问题都成立。但是，对于**凸优化问题**，在满足某些约束规范（如Slater条件）的情况下，强对偶性成立。
    *   **重要推论 (Theorem 12.12)**: 对于一个凸优化问题，如果$(\\bar{x}, \\bar{\\lambda})$是一个满足KKT条件的点，那么$\\bar{\\lambda}$就是对偶问题的一个解，并且强对偶性成立。

5.  **Wolfe 对偶**
    *   这是另一种形式的对偶问题，它将求解$\\inf_x \mathcal{L}(x, \lambda)$的条件（即$\\nabla_x \mathcal{L}(x, \lambda)=0$）直接作为对偶问题的约束。
    *   **形式**: 
        $$\\max_{x, \lambda} \mathcal{L}(x, \lambda) \quad \text{s.t. } \nabla_x \mathcal{L}(x, \lambda) = 0, \lambda \geq 0$$
    *   对于凸问题，Wolfe对偶与拉格朗日对偶是等价的。

# 学习要点

-   **核心构造**: 掌握从原始问题到拉格朗日函数，再到对偶函数，最后到对偶问题的构造过程。
-   **凹函数**: 记住对偶函数$q(\lambda)$总是一个凹函数，无论原始问题性质如何。
-   **弱对偶性**: 理解“对偶提供下界”这一基本性质，它永远成立。
-   **强对偶性**: 明白强对偶性（零间隙）通常只在凸优化问题中成立，并且它将原始问题的KKT点与对偶问题的最优点联系起来。
-   **应用**: 知道对偶性在理论分析和算法设计中的重要作用。例如，某些算法可以通过求解更容易的对偶问题来解决原始问题。

# 实践应用

-   **线性规划 (LP)**: 线性规划的对偶问题也是一个线性规划，LP的对偶理论非常完善且应用广泛（见Chapter 13）。
-   **二次规划 (QP)**: 凸二次规划的对偶问题也是一个二次规划，如Example 12.12所示。
-   **算法设计**: 增广拉格朗日法（Chapter 17）就是基于对偶思想，通过迭代地更新乘子$\\lambda$来求解原始问题。内点法也与对偶理论有深刻联系。
-   **提供下界**: 在一些困难的（如非凸或整数）优化问题中，即使无法求解原始问题，也可以通过求解其对偶问题（或其松弛形式）来获得原始问题最优值的一个有效下界，这在分支定界等算法中非常有用。
