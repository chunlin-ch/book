# 知识点概述

变量消去法是一种处理等式约束的基本技巧。其思想是利用$m$个等式约束来显式地消去$m$个变量，从而将原问题转化为一个变量更少、约束更简单的（甚至是无约束的）问题。虽然这个思想很自然，但在非线性问题中直接使用可能引入问题，因此它主要被用于处理**线性**等式约束。

# 教材原文

> When dealing with constrained optimization problems, it is natural to try to use the constraints to eliminate some of the variables from the problem, to obtain a simpler problem with fewer degrees of freedom. Elimination techniques must be used with care, however, as they may alter the problem or introduce ill conditioning.

# 详细解释

1.  **非线性消元的风险**
    *   直接用非线性等式约束来消去变量是危险的。如例子 $\min x^2+y^2$ s.t. $(x-1)^3=y^2$，如果消去$y$得到 $\min x^2+(x-1)^3$，问题会变为无下界，从而得出错误结论。这是因为消元过程忽略了隐含的约束（此例中为$x >= 1$）。
    *   因此，大多数实用算法不采用非线性消元，而是先将约束线性化再进行消元。

2.  **线性等式约束的变量消去**
    *   考虑问题 $\min f(x)$ s.t. $Ax=b$，其中$A$是$m 	imes n$矩阵 ($m<n$)且行满秩。
    *   **核心思想**: 将变量$x$分解为两部分：一部分是满足$Ax=b$的**特解**，另一部分来自$A$的**零空间**（null space）。任何可行点$x$都可以表示为：
        $$x = x_{\text{particular}} + Zv$$
        其中$AZv=0$，即$Z$的列构成了$A$的零空间的一组基，$v$是$n-m$维的向量。
    *   通过这种分解，原约束问题转化为了一个关于$v$的**无约束**优化问题：
        $$\min_v f(x_{\text{particular}} + Zv)$$
    *   这个降维后的问题可以用任何无约束优化技术求解。

3.  **消元策略 (如何选择特解和零空间基)**
    *   **简单消元法 (Simple Elimination)**:
        1.  将$A$的列分为一个$m 	imes m$的非奇异**基矩阵**$B$和一个$m 	imes (n-m)$的非基矩阵$N$。相应地，变量$x$分为基变量$x_B$和非基变量$x_N$。
        2.  从$Ax=Bx_B+Nx_N=b$中解出基变量：$x_B = B^{-1}b - B^{-1}Nx_N$。
        3.  将此表达式代入目标函数$f(x)$，得到一个只关于非基变量$x_N$的无约束优化问题。
        4.  这等价于选择特解为 $[B^{-1}b, 0]^T$，零空间基为 $Z = \begin{bmatrix} -B^{-1}N \\ I \end{bmatrix}$。
        *   **缺点**: 如果基矩阵$B$是病态的（ill-conditioned），那么计算出的$Z$可能会包含非常大的元素，导致数值不稳定。

    *   **一般约化策略 (General Reduction / Orthogonal Factorization)**:
        1.  通过对$A^T$进行**QR分解**来找到$A$的零空间的正交基$Z$。即 $A^T = Q\begin{bmatrix} R \\ 0 \end{bmatrix} = [Q_1, Q_2]\begin{bmatrix} R \\ 0 \end{bmatrix}$，则$Z=Q_2$。
        2.  选择特解为满足$Ax=b$的**最小范数解**：$x_{\text{particular}} = A^T(AA^T)^{-1}b$。
        3.  任何可行点可以表示为 $x = A^T(AA^T)^{-1}b + Zv$。
        *   **优点**: 这种方法数值上非常稳健，因为$Z$的列是正交的。它避免了简单消元法可能出现的数值问题。
        *   **缺点**: 对于大规模稀疏矩阵$A$，计算QR分解的成本可能很高。

4.  **不等式约束的影响**
    *   如果问题中还包含不等式约束，消元法可能会使问题变得更复杂。例如，简单的变量界约束$x >= 0$在消元后可能会变成复杂的线性不等式约束，从而增加了求解难度。因此，消元法是否适用需要视具体情况而定。

# 学习要点

-   **核心分解**: 理解任何可行点都可以分解为一个特解和一个零空间中的向量的线性组合。
-   **降维**: 变量消去的本质是将一个$n$维的等式约束问题转化为一个$n-m$维的无约束问题。
-   **两种主要策略**: 掌握简单消元法（基于基矩阵）和正交分解法（基于QR分解）的原理、优缺点和数值特性。
-   **数值稳定性**: 认识到简单消元法可能存在数值不稳定性，而正交分解法更稳健但成本更高。
-   **适用性**: 变量消去法是处理**线性等式约束**的强大工具，但在处理非线性等式约束或存在许多不等式约束时需谨慎使用。

# 实践应用

-   **序列二次规划 (SQP)**: 在SQP的EQP（等式约束QP）方法中，子问题是二次目标函数和线性等式约束，变量消去法是求解该子问题的核心技术之一。
-   **内点法**: 在求解内点法的线性系统时，也常常用到类似的约化思想。
-   **最优控制**: 在最优控制问题的离散化形式中，常常出现大量的线性等式约束，变量消去法是求解这类大规模问题的关键。
