# 知识点概述

线性共轭梯度（CG）法是一种高效的迭代方法，用于求解大型对称正定线性方程组 $Ax=b$，这等价于最小化二次函数 $\phi(x) = \frac{1}{2}x^T A x - b^T x$。其核心思想是生成一组关于矩阵A共轭的搜索方向，并沿着这些方向进行精确的一维搜索。由于其出色的收敛性质和极低的内存需求，它在科学计算和优化领域得到了广泛应用。

# 教材原文

> A set of nonzero vectors {p_0, p_1, \ldots, p_l} is said to be **conjugate** with respect to the symmetric positive definite matrix $A$ if
> $$p_i^T A p_j = 0, \quad \text{for all } i \neq j. \tag{5.5}$$ 
> The conjugate gradient method is a conjugate direction method with a very special property: In generating its set of conjugate vectors, it can compute a new vector $p_k$ by using only the previous vector $p_{k-1}$.
> $$p_k = -r_k + \beta_k p_{k-1}, \tag{5.13}$$ 
> where $r_k$ is the residual $Ax_k - b$.

# 详细解释

1.  **共轭方向法 (Conjugate Direction Methods)**
    *   **共轭性**: 两个非零向量$p_i, p_j$关于对称正定矩阵$A$共轭，意味着$p_i^T A p_j = 0$。一组共轭方向是线性无关的。
    *   **核心定理**: 对于n维二次函数，如果沿着一组n个A-共轭的方向进行精确的一维最小化，最多n步即可达到最小值点。这被称为**二次终止性 (Quadratic Termination)**。
    *   **几何意义**: 在经过变量变换使得Hessian矩阵为单位阵的新坐标系下，共轭方向对应于正交方向。因此，共轭方向法相当于在新坐标系下进行坐标轴轮换搜索，n步即可完成。

2.  **共轭梯度法的推导**
    *   CG法是一种特殊的共轭方向法，它以一种非常经济的方式生成共轭方向。
    *   第一个搜索方向$p_0$取为最速下降方向：$p_0 = -r_0 = -(Ax_0 - b)$。
    *   后续的搜索方向$p_k$由当前的最速下降方向$-r_k$和前一个搜索方向$p_{k-1}$线性组合而成：$p_k = -r_k + \beta_k p_{k-1}$。
    *   系数$eta_k$的选择是为了保证$p_k$与$p_{k-1}$是A-共轭的，可以推导出多个等价公式，最常用的是：
        $$\beta_k = \frac{r_k^T r_k}{r_{k-1}^T r_{k-1}}$$

3.  **实用CG算法 (Algorithm 5.2)**
    *   **输入**: 初始点 $x_0$。
    *   **初始化**: $r_0 = Ax_0 - b$, $p_0 = -r_0$, $k=0$。
    *   **迭代**: 当 $r_k \neq 0$ 时循环：
        1.  计算步长: $\alpha_k = \frac{r_k^T r_k}{p_k^T A p_k}$。
        2.  更新迭代点: $x_{k+1} = x_k + \alpha_k p_k$。
        3.  更新残差: $r_{k+1} = r_k + \alpha_k A p_k$。
        4.  计算beta: $\beta_{k+1} = \frac{r_{k+1}^T r_{k+1}}{r_k^T r_k}$。
        5.  更新搜索方向: $p_{k+1} = -r_{k+1} + \beta_{k+1} p_k$。
    *   **特点**: 每次迭代只需要一次矩阵-向量乘法 ($Ap_k$)，几次向量内积和向量加法。不需要存储整个矩阵$A$，只需要能计算$A$与向量的乘积即可，内存开销非常小。

4.  **收敛速度**
    *   CG法的收敛速度与矩阵$A$的特征值分布密切相关。
    *   如果$A$有$r$个不同的特征值，CG法最多$r$步收敛。
    *   如果$A$的特征值聚集在少数几个小区间内，CG法会很快收敛。例如，如果有$m$个大特征值，其余特征值聚集在1附近，那么大约$m+1$步后，误差会大幅下降。
    *   收敛率的上界与矩阵的条件数$\\kappa(A)$有关：
        $$\|x_k - x^*\|_A \leq 2 \left(\frac{\sqrt{\\kappa(A)}-1}{\sqrt{\\kappa(A)}+1}\right)^k \|x_0 - x^*\|_A$$
        这个界比最速下降法的界（依赖于$\\kappa(A)$）要好得多，说明CG法通常比最速下降法快得多。

5.  **预处理 (Preconditioning)**
    *   为了加速收敛，可以对原方程进行变换，即求解 $\\hat{A}\\hat{x}=\\hat{b}$，其中 $\\hat{A}=C^{-T}AC^{-1}$。选择合适的预处理器$C$（或$M=C^TC$），使得$\\hat{A}$的特征值分布更好（例如，更聚集，条件数更小）。
    *   常用的预处理技术包括不完全Cholesky分解（IC）、SSOR等。

# 学习要点

-   **共轭性**: 理解$p_i^T A p_j = 0$的定义及其几何意义。
-   **二次终止性**: 掌握共轭方向法对于二次函数在n步内收敛的核心性质。
-   **CG算法流程**: 熟记Algorithm 5.2的迭代步骤，特别是$\alpha_k$和$\beta_k$的计算公式。
-   **收敛特性**: 了解CG的收敛速度不仅依赖于条件数，更依赖于特征值的整体分布情况，特别是聚集性。
-   **预处理**: 明白预处理是通过改善矩阵的谱结构来加速CG收敛的关键技术。

# 实践应用

-   **大规模线性系统**: CG法是求解由偏微分方程离散化等产生的大型稀疏对称正定线性方程组的首选迭代方法。
-   **无约束优化**: 作为牛顿法（特别是信赖域-牛顿法和不精确牛顿法）的子问题求解器，用于求解牛顿方程组 $B_k p_k = -\nabla f_k$。
-   **非线性优化**: 线性CG法的思想被推广到非线性问题，形成了非线性共轭梯度法。
