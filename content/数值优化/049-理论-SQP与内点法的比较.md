# 知识点概述

序列二次规划（SQP）和内点法是求解非线性约束优化问题的两大主流算法。它们在处理约束和构造子问题的方式上有着根本的不同，从而导致了各自在计算性能、稳健性和适用性上的差异。SQP通过求解一系列二次规划（QP）子问题来迭代，而内点法则通过引入障碍项将问题转化为一系列等式约束子问题。对于特定问题，哪种方法更优并没有绝对的答案，但它们各自的特点使它们在不同场景下各有优势。

# 教材原文

> Both SQP and interior-point methods are formidable, and neither approach can be declared the winner in all circumstances. ...
> SQP methods are generally able to make more progress on each iteration, so they may converge in fewer iterations. ... For interior-point methods, by contrast, the cost of each iteration is relatively predictable. ...
> Interior-point methods are more easily able to exploit the structure of the problem, particularly second-order structure. ...
> SQP methods can be more easily “warm-started” than interior-point methods.

# 详细解释

| 特征 | 序列二次规划 (SQP) | 内点法 (Interior-Point) |
| :--- | :--- | :--- |
| **核心思想** | 在当前点对问题进行**二次近似**，求解一个**QP子问题**来获得搜索方向。 | 引入**对数障碍项**处理不等式约束，将问题转化为一系列**等式约束**子问题，并追踪中心路径。 |
| **子问题** | 二次规划 (QP) | 大型、稀疏、对称不定的线性系统 (KKT系统) |
| **迭代成本** | **变化较大**。取决于QP子问题的求解难度（特别是积极集的确定）。 | **相对稳定**。主要成本在于分解一个大型的KKT矩阵。 |
| **迭代次数** | 通常**较少**。每一步都试图获得一个“完整”的牛顿步，进展较快。 | 通常**较多**。每一步都比较保守，需要在中心路径附近移动。 |
| **对Hessian的处理** | 需要保证QP子问题中的Hessian近似是**正定**的（对于线搜索SQP），否则QP子问题可能无解。 | 可以更自然地处理**非正定**的拉格朗日Hessian，通过修正惯性来获得下降方向。 |
| **热启动 (Warm Start)** | **非常有效**。如果从一个接近最优解的初始点（和积极集）开始，SQP可以很快收敛。 | **效果不佳**。内点法必须从一个严格可行的点开始，即使提供了好的初始点，也需要一定数量的迭代才能“找到”中心路径。 |
| **对问题结构的利用** | 较难利用二阶结构。 | **更容易利用**。如果Hessian矩阵具有稀疏结构，内点法的KKT系统也会是稀疏的，从而可以利用稀疏线性代数高效求解。 |
| **敏感性** | 对函数的缩放和参数的选择（如价值函数参数）可能更敏感。 | 相对不那么敏感。 |
| **软件实现** | SNOPT, KNITRO, FILTERSQP | IPOPT, KNITRO, LOQO |

# 学习要点

-   **根本区别**: SQP是“外部”方法，它在每次迭代中猜测积极集；内点法是“内部”方法，它通过障碍项始终保持在可行域内部，避免了对积极集的组合搜索。
-   **迭代次数 vs. 迭代成本**: 理解两者之间的权衡。SQP迭代次数少但单次成本变化大；内点法迭代次数多但单次成本稳定。
-   **热启动**: 这是一个关键的实践差异。当需要求解一系列相似的问题时（例如在模型预测控制或分支定界中），SQP的热启动能力是一个巨大优势。
-   **大规模问题**: 对于大规模、稀疏的问题，内点法通常更具优势，因为它们能更好地利用稀疏线性代数技术来求解KKT系统。
-   **没有绝对的赢家**: 两种方法都是强大而复杂的，在不同的问题和场景下各有千秋。现代优化求解器（如KNITRO）同时提供两种算法选项，让用户可以根据问题特性进行选择。

# 实践应用

-   **SQP适用场景**: 
    *   函数和梯度求值成本高的“黑箱”优化问题，因为SQP通常需要更少的函数求值次数。
    *   需要热启动的应用，如实时优化、模型预测控制（MPC）。
    *   中小型、稠密的问题。
-   **内点法适用场景**: 
    *   大规模、稀疏的问题，例如来自偏微分方程（PDE）约束的优化问题。
    *   线性规划（LP）和二次规划（QP），内点法在这些领域取得了巨大成功。
    *   当不需要热启动时。
