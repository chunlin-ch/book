# 知识点概述

对称秩一（Symmetric Rank-One, SR1）方法是另一种重要的拟牛顿法。与BFGS（秩二更新）不同，SR1每次迭代只对Hessian近似矩阵进行秩一修正。它的主要优点是能够生成非常好的Hessian近似，甚至在某些情况下可以n步内精确得到二次函数的海森矩阵。其主要缺点是不保证生成的近似矩阵是正定的，并且更新公式可能无定义。因此，SR1方法更适合与信赖域框架结合使用。

# 教材原文

> The only symmetric rank-1 updating formula that satisfies the secant equation is given by
> $$B_{k+1} = B_k + \frac{(y_k - B_k s_k)(y_k - B_k s_k)^T}{(y_k - B_k s_k)^T s_k}. \tag{6.24}$$
> The corresponding update for the inverse Hessian approximation $H_k$ is:
> $$H_{k+1} = H_k + \frac{(s_k - H_k y_k)(s_k - H_k y_k)^T}{(s_k - H_k y_k)^T y_k}. \tag{6.25}$

# 详细解释

1.  **SR1 更新公式**
    *   **推导**: SR1公式是通过寻找一个对称的秩一矩阵 $vv^T$ 添加到当前Hessian近似$B_k$上，使得新的矩阵$B_{k+1} = B_k + vv^T$满足割线方程 $B_{k+1}s_k = y_k$ 而推导出来的唯一解。
    *   **公式**: 如上(6.24)和(6.25)所示。

2.  **SR1方法的性质**
    *   **优点**:
        *   **优秀的Hessian近似**: SR1生成的矩阵$B_k$往往能很好地逼近真实的Hessian矩阵，即使对于非凸函数也是如此。
        *   **二次终止性**: 对于二次函数，如果步长为1且更新有定义，SR1方法最多n步即可得到精确的Hessian逆矩阵$A^{-1}$，并在第n+1步找到最小值。
        *   **满足割线方程的历史性**: 对于二次函数，SR1更新能保证$H_k$满足所有历史步的割线方程，即 $H_k y_j = s_j$ for $j=0, ..., k-1$。这是BFGS在精确线搜索下才有的性质。
    *   **缺点**:
        1.  **不保证正定性**: 即使$B_k$是正定的，$B_{k+1}$也可能不是。这使得SR1不适合与传统的线搜索方法（需要下降方向）直接结合。
        2.  **可能无定义**: 更新公式的分母 $(y_k - B_k s_k)^T s_k$ （或 $(s_k - H_k y_k)^T y_k$）可能为零，导致更新失败。这种情况虽然不常见，但确实可能发生。

3.  **SR1的实用算法**
    *   **跳过更新 (Skipping)**: 为了处理分母为零或接近零的情况，实用的SR1算法会引入一个保护措施。只有当分母足够大时才进行更新，例如满足：
        $$|s_k^T(y_k - B_k s_k)| \geq r \|s_k\| \|y_k - B_k s_k\| \tag{6.26}$$
        其中$r \in (0,1)$是一个小常数（如$10^{-8}$）。如果不满足此条件，则不更新，令$B_{k+1}=B_k$。
    *   **与信赖域结合**: 由于SR1能产生不定矩阵，它与信赖域框架是天然的结合。信赖域方法不需要Hessian近似是正定的，因此可以充分利用SR1近似真实Hessian（包括其不定性）的能力。Algorithm 6.2 (SR1 Trust-Region Method) 就是一个典型的例子。

# 学习要点

-   **秩一与秩二**: 明确SR1是秩一更新，而BFGS是秩二更新。
-   **核心优缺点**: 记住SR1的优点（优秀的Hessian近似，二次终止性）和缺点（不保正定，可能无定义）。
-   **保护机制**: 理解跳过更新是SR1算法稳健性的关键。
-   **与信赖域的适配性**: 明白为什么SR1的“缺点”（不保正定）在信赖域框架下反而可以成为一个优点（能捕捉负曲率信息）。

# 实践应用

-   SR1方法，特别是当它与信赖域框架结合时，是一种非常有效的优化算法。
-   在约束优化中，拉格朗日函数的Hessian矩阵通常是未知的且可能非正定，SR1是近似该矩阵的一个很好的选择，因此在SQP等方法中得到应用。
-   限制内存的SR1版本（L-SR1）也已被开发出来，用于求解大规模问题。
