# 知识点概述

约束规范（Constraint Qualification, CQ）是约束优化理论中的一个核心概念。它是一组施加在约束函数上的条件，用以确保在某个可行点，可行域的局部几何性质能够被其线性化近似所准确描述。满足约束规范是保证KKT条件成为最优性必要条件的前提。最常用和最重要的约束规范是线性无关约束规范（LICQ）。

# 教材原文

> Constraint qualifications are assumptions that ensure similarity of the constraint set $\Omega$ and its linearized approximation, in a neighborhood of $x^*$.
> 
> **Definition 12.4 (LICQ).**
> Given the point $x$ and the active set $\mathcal{A}(x)$ ..., we say that the linear independence constraint qualification (LICQ) holds if the set of active constraint gradients {$\nabla c_i(x), i \in \mathcal{A}(x)$} is linearly independent.

# 详细解释

1.  **动机：为何需要约束规范？**
    *   KKT条件的推导依赖于一个基本思想：在最优点，不存在任何一个既能保持可行又能使目标函数下降的方向。
    *   我们通过线性化来判断是否存在这样的方向。具体来说，我们定义了**切锥（Tangent Cone）** $T_\Omega(x^*)$ 和 **一阶可行方向锥（Linearized Feasible Direction Cone）** $\mathcal{F}(x^*)$。
        *   **切锥 $T_\Omega(x^*)$**: 几何概念，由所有从$x^*$出发的可行序列的极限方向组成，精确地描述了可行域的局部几何。
        *   **可行方向锥 $\mathcal{F}(x^*)$**: 代数概念，由满足积极约束梯度线性化条件的向量组成，是我们用来近似$T_\Omega(x^*)$的工具。
    *   如果$\mathcal{F}(x^*)$不能准确地描述$T_\Omega(x^*)$（例如，$\mathcal{F}(x^*)$比$T_\Omega(x^*)$大得多），那么基于$\mathcal{F}(x^*)$推导出的KKT条件就可能不成立。约束规范的作用就是保证 $\mathcal{F}(x^*) = T_\Omega(x^*)$。

2.  **主要的约束规范**
    *   **线性无关约束规范 (Linear Independence Constraint Qualification, LICQ)**:
        *   **定义**: 在点$x^*$处，所有**积极约束**（包括所有等式约束和值为零的不等式约束）的梯度向量是线性无关的。
        *   **特点**: 这是最常用、最容易验证的约束规范。如果LICQ成立，那么KKT条件中的拉格朗日乘子是唯一的。许多算法的理论分析都依赖于LICQ。

    *   **Mangasarian-Fromovitz 约束规范 (MFCQ)**:
        *   **定义**: 在点$x^*$处，所有等式约束的梯度线性无关，并且存在一个向量$w$使得：
            *   $w$与所有等式约束梯度正交：$\nabla c_i(x^*)^T w = 0, \forall i \in \mathcal{E}$。
            *   $w$严格指向所有积极不等式约束的可行方向内部：$\nabla c_i(x^*)^T w > 0, \forall i \in \mathcal{A}(x^*) \cap \mathcal{I}$。
        *   **特点**: MFCQ比LICQ更弱（即LICQ成立则MFCQ必成立，反之不然）。当MFCQ成立时，KKT条件中的拉格朗日乘子集合是有界集（但不一定是单点集）。

    *   **线性约束规范 (Linear Constraints CQ)**:
        *   **定义**: 如果在点$x^*$处，所有的积极约束函数都是线性的。
        *   **特点**: 这是一个很强的条件，但在线性规划（LP）和二次规划（QP）中自然满足。它也保证了$\mathcal{F}(x^*) = T_\Omega(x^*)$。

# 学习要点

-   **CQ的核心作用**: 连接可行域的几何（切锥）和代数（线性化可行方向锥），是KKT条件成立的“许可证”。
-   **LICQ**: 掌握其定义——积极约束梯度线性无关。这是最重要、最常用的CQ。
-   **CQ的强弱关系**: 了解 LICQ $\Rightarrow$ MFCQ。知道MFCQ更一般化，但LICQ在算法设计和分析中更方便。
-   **何时失效**: 能够识别一些典型的CQ失效情况，例如两个不等式约束在一点相切（如图12.10），或者在一点有超过n个积极约束。

# 实践应用

-   在设计和分析算法时，约束规范是证明全局收敛和局部快速收敛的关键假设。
-   当一个算法在某个问题上表现异常或失败时，检查在疑似解的点上约束规范是否满足或接近失效，是诊断问题的一个重要方向。
-   例如，当LICQ不满足时，KKT系统中的Jacobian矩阵会变得奇异，这会导致基于牛顿法的SQP或内点法在求解线性子系统时遇到数值困难。
