# 知识点概述

线性最小二乘问题是目标函数为二次函数且无约束的特殊优化问题，其形式为 $\min_x f(x) = \frac{1}{2}\|Jx-y\|^2$。这个问题的解可以通过求解一个线性方程组——**正规方程组 (Normal Equations)**——来获得。主要有三种求解该问题的数值方法：基于Cholesky分解的正规方程法、基于QR分解的方法和基于奇异值分解（SVD）的方法。这些方法在计算成本、数值稳定性和提供解的敏感性信息方面各有优劣。

# 教材原文

> The problem of minimizing (10.7) is called a linear least-squares problem. We can write the residual vector as $r(x)=Jx-y$ ... so that the objective is
> $$f(x) = \frac{1}{2}\|Jx-y\|^2. \tag{10.13}$$
> The KKT conditions ... state that any point $x^*$ for which $\nabla f(x^*)=0$ is the global minimizer of $f$. Therefore, $x^*$ must satisfy the following linear system of equations:
> $$J^T J x^* = J^T y. \tag{10.14}$$
> These are known as the normal equations for (10.13).

# 详细解释

线性最小二乘问题是凸优化问题，其最优解$x^*$满足梯度为零的条件，即正规方程组(10.14)。下面是求解该问题的三种主要算法。

1.  **正规方程法 (Normal Equations Method)**
    *   **步骤**:
        1.  显式地计算矩阵 $J^T J$ 和向量 $J^T y$。
        2.  对对称正定矩阵 $J^T J$ 进行 **Cholesky 分解**，得到 $J^T J = \bar{R}^T \bar{R}$。
        3.  通过两次三角回代（求解 $\bar{R}^T z = J^T y$ 和 $\bar{R} x^* = z$）得到解$x^*$。
    *   **优点**: 当$m \gg n$时，计算$J^T J$的成本可能低于直接分解$J$。在某些稀疏问题中也可能更高效。
    *   **缺点**: **数值不稳定**。矩阵$J^T J$的条件数是$J$的条件数的平方（$\kappa(J^T J) = \kappa(J)^2$）。如果$J$本身是病态的，那么$J^T J$会更加病态，导致Cholesky分解失败或解的精度很差。

2.  **QR分解法 (QR Factorization Method)**
    *   **思想**: 利用正交变换不改变向量欧几里得范数的性质。对矩阵$J$进行QR分解：$J=Q\begin{bmatrix} R \\ 0 \end{bmatrix}$，其中$Q$是$m \times m$正交矩阵，$R$是$n \times n$上三角矩阵。
    *   **步骤**:
        1.  对$J$进行QR分解。
        2.  目标函数变为：$\|Jx-y\|^2 = \|Q^T(Jx-y)\|^2 = \|Rx - Q_1^T y\|^2 + \|Q_2^T y\|^2$，其中$Q_1$是$Q$的前n列。
        3.  通过求解上三角方程组 $Rx = Q_1^T y$ 来使第一项为零，从而得到解$x^*$。
    *   **优点**: **数值稳定性好**。该方法直接在$J$上操作，避免了条件数的平方，因此计算出的解通常更精确。
    *   **缺点**: 对于稠密问题，计算QR分解的成本通常高于正规方程法。

3.  **奇异值分解法 (SVD Method)**
    *   **思想**: 利用SVD分解 $J=U\begin{bmatrix} S \\ 0 \end{bmatrix}V^T$ 来分析和求解问题，其中$U,V$是正交矩阵，$S$是对角矩阵，其对角元为奇异值 $\sigma_i$。
    *   **步骤**: 类似于QR分解，最终解可以表示为：
        $$x^* = V S^{-1} U_1^T y = \sum_{i=1}^n \frac{u_i^T y}{\sigma_i} v_i$$
        其中$u_i, v_i$是$U,V$的列向量。
    *   **优点**: **最稳健、最可靠**的方法。它不仅能处理满秩问题，还能处理**秩亏（rank-deficient）**问题。此外，SVD提供了关于解的**敏感性**的宝贵信息：小的奇异值$\\sigma_i$表明解$x^*$对数据$y$和矩阵$J$的扰动非常敏感。
    *   **缺点**: 计算成本是三者中最高的。

# 学习要点

-   **正规方程**: 记住 $J^T J x = J^T y$ 是线性最小二乘问题的核心方程。
-   **方法比较**: 掌握三种主要算法在**数值稳定性**和**计算成本**上的权衡。
    *   **稳定性**: SVD > QR > 正规方程法。
    *   **成本 (一般情况)**: 正规方程法 < QR < SVD。
-   **条件数**: 理解为什么正规方程法会平方条件数，以及这为什么会导致数值不稳定。
-   **SVD的优势**: 了解SVD不仅能求解，还能诊断问题。小的奇异值是病态或秩亏的信号。
-   **大规模问题**: 对于非常大的问题，可以使用迭代法（如共轭梯度法CG）来求解正规方程组，此时只需要计算矩阵-向量积（$Jv$和$J^T u$），而无需显式形成$J^T J$。

# 实践应用

-   **算法选择**: 
    *   如果问题规模不大且$J$良态，**正规方程法**因其简单高效而被广泛使用。
    *   如果对数值精度有较高要求，或者怀疑$J$可能病态，**QR分解法**是更可靠的选择。
    *   如果需要分析解的稳定性和敏感性，或者$J$是秩亏或接近秩亏的，**SVD法**是最佳选择。
-   线性最小二乘是许多非线性优化算法（如Gauss-Newton法、Levenberg-Marquardt法）的核心子问题。
