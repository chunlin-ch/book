# 知识点概述

等式约束二次规划（Equality-Constrained Quadratic Program, EQP）是目标函数为二次函数、约束为线性等式的一类优化问题。这类问题是二次规划中最简单的情形，其解可以通过求解一个线性的KKT（Karush-Kuhn-Tucker）系统直接获得。求解这个KKT系统是许多更复杂的优化算法（如SQP法）的核心步骤，因此有多种高效的求解策略，包括直接分解KKT矩阵、Schur-complement法和零空间法。

# 教材原文

> The equality-constrained QP is as follows:
> $$\min_x q(x) = \frac{1}{2}x^T G x + x^T c \quad \text{subject to } Ax=b. \tag{16.3}​$$
> The first-order necessary conditions for $x^*$ to be a solution ... state that there is a vector $\lambda^*$ such that the following system of equations is satisfied:
> $$\begin{bmatrix} G & -A^T \ A & 0 \end{bmatrix} \begin{bmatrix} x^* \ \lambda^* \end{bmatrix} = \begin{bmatrix} -c \ b \end{bmatrix}. \tag{16.4}​$$

# 详细解释

1.  **KKT系统**
    *   EQP的最优解$(x^*, \lambda^*)$是其KKT条件的解，如公式(16.4)所示。这是一个对称但**不定**的线性方程组，被称为KKT系统或增广系统。
    *   **可解性 (Lemma 16.1)**: 当约束矩阵$A$行满秩，并且目标函数的Hessian矩阵$G$在$A$的零空间上是正定的（即**投影Hessian** $Z^T G Z$正定，其中$Z$是$A$的零空间基），KKT矩阵是**非奇异**的，此时EQP有唯一全局解。
    *   如果$Z^T G Z$是半正定的，解存在但不唯一；如果$Z^T G Z$有负特征值，问题无下界（除非可行域为空）。

2.  **求解KKT系统的直接方法**

    *   **方法一：对称不定分解 (Symmetric Indefinite Factorization)**
        *   **思想**: 直接对整个$(n+m) \times (n+m)$的KKT矩阵进行分解，例如 $P^T K P = LBL^T$，其中$B$是块对角矩阵（含1x1和2x2块）。
        *   **优点**: 概念上直接，适用于一般情况。
        *   **缺点**: 对于大规模稀疏问题，如果填充（fill-in）严重，成本会很高。

    *   **方法二：Schur-Complement 法 (或 Range-Space 法)**
        *   **适用条件**: Hessian矩阵$G$本身是可逆的（通常是正定的）。
        *   **思想**: 通过块消元，先解出乘子$\\lambda^*$，再解出$x^*$。
        *   **步骤**:
            1.  从KKT系统的第一行解出$x^*$: $x^* = G^{-1}(A^T \lambda^* - c)$。
            2.  代入第二行 $Ax^*=b$，得到关于$\\lambda^*$的方程：
                $$(AG^{-1}A^T) \lambda^* = AG^{-1}c + b$$ 
            3.  求解这个$m \times m$的对称正定系统得到$\\lambda^*$，然后回代得到$x^*$。
        *   **优点**: 当$G$容易求逆（例如对角阵）或者约束数量$m$远小于变量数量$n$时非常有效。

    *   **方法三：零空间法 (Null-Space Method)**
        *   **思想**: 将解$x^*$分解为两部分：一个满足$Ax=b$的特解$x_p$，和一个在约束零空间中的分量$Z v$。即 $x^* = x_p + Zv$。
        *   **步骤**:
            1.  找到一个特解$x_p$（例如，通过QR分解或LU分解）。
            2.  找到$A$的零空间的一组基$Z$。
            3.  将$x=x_p+Zv$代入目标函数，问题转化为一个关于$v$的无约束二次规划：
                $$\min_v \frac{1}{2} v^T (Z^T G Z) v + (c+Gx_p)^T Z v$$ 
            4.  求解上述问题的最优解$v^*$（通过求解线性方程组 $(Z^T G Z)v^* = -Z^T(c+Gx_p)$），然后得到 $x^* = x_p + Zv^*$。
        *   **优点**: 当零空间的维度$n-m$很小时非常有效。它不要求$G$可逆，只需要投影Hessian $Z^T G Z$正定即可。

# 学习要点

-   **KKT系统**: 掌握EQP的核心就是求解一个大型的线性KKT系统。
-   **三种方法**: 理解并区分三种主要的直接求解策略：直接分解整个KKT矩阵、Schur-Complement法（消去$x$）和零空间法（消去约束）。
-   **适用场景**: 了解三种方法的适用场景和计算权衡。
    *   Schur-Complement法: $G$可逆且$m$小。
    *   零空间法: $n-m$小。
    *   直接分解法: 通用，但依赖于稀疏线性代数软件的性能。
-   **投影Hessian**: 理解$Z^T G Z$的正定性是保证EQP有唯一解的关键条件。

# 实践应用

-   **SQP子问题**: EQP是序列二次规划（SQP）方法中EQP变体的核心子问题。在每次迭代中，都需要求解一个EQP来获得搜索方向。
-   **内点法**: 在内点法的最后阶段，当有效约束集确定后，算法的行为类似于求解一个EQP。
-   **最优控制**: 离散时间最优控制问题常常可以被建模为具有特殊结构的EQP。
