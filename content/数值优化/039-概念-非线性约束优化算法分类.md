# 知识点概述

求解一般非线性约束优化问题的算法种类繁多，但可以大致分为几个主要类别。这些类别在处理约束和构造子问题的方式上有所不同。主要的类别包括：二次规划（作为子问题）、罚函数与增广拉格朗日法、序列二次规划（SQP）法和内点（障碍）法。

# 详细解释

1.  **二次规划 (Quadratic Programming, QP)**
    *   **定位**: 这本身是一类优化问题（二次目标，线性约束），但它也是许多更复杂的非线性规划算法的核心**子问题**。
    *   **作用**: SQP和某些内点法在每次迭代中都需要求解一个QP子问题来产生搜索方向。
    *   **相关章节**: Chapter 16

2.  **罚函数与增广拉格朗日法 (Penalty and Augmented Lagrangian Methods)**
    *   **思想**: 将约束优化问题转化为一系列的**无约束优化**子问题。通过在目标函数中加入“惩罚项”来对违反约束的行为进行惩罚。
    *   **二次罚函数法**: 惩罚项是约束违反量的平方乘以一个罚参数$\mu$。通过逐步增大$\mu$，迫使子问题的解趋近于原始问题的可行解。缺点是当$\mu$很大时，子问题会变得病态。
        $$Q(x; \mu) = f(x) + \frac{\mu}{2} \sum_{i \in \mathcal{E}} c_i^2(x)$$
    *   **增广拉格朗日法 (方法乘子法)**: 在罚函数的基础上加入了拉格朗日乘子的估计。这可以避免罚参数$\mu$需要趋于无穷大，从而克服了二次罚函数法的病态问题。
        $$\mathcal{L}_A(x, \lambda; \mu) = f(x) - \lambda^T c(x) + \frac{\mu}{2} \|c(x)\|^2$$
    *   **相关章节**: Chapter 17

3.  **序列二次规划 (Sequential Quadratic Programming, SQP)**
    *   **思想**: 在当前迭代点，通过对拉格朗日函数做二次近似、对约束做线性近似，来构造一个**二次规划（QP）子问题**。将这个QP子问题的解作为搜索方向。
    *   **子问题形式**: 
        $$\min_p \frac{1}{2} p^T (\nabla_{xx}^2 \mathcal{L}_k) p + \nabla f_k^T p$$
        $$\text{s.t. } \nabla c_i(x_k)^T p + c_i(x_k) = 0, \quad i \in \mathcal{E}$$
        $$\nabla c_i(x_k)^T p + c_i(x_k) \geq 0, \quad i \in \mathcal{I}$$
    *   **特点**: SQP方法通常被认为是求解中小型非线性规划问题最高效的方法之一，具有快速的局部收敛性（超线性）。其全局化通常通过线搜索或信赖域方法实现。
    *   **相关章节**: Chapter 18

4.  **内点法 (Interior-Point Methods)**
    *   **思想**: 将不等式约束通过引入**障碍项**（如对数函数）合并到目标函数中，从而将问题转化为一系列的等式约束优化问题。算法的迭代点始终保持在不等式约束可行域的严格内部。
    *   **子问题形式** (障碍问题):
        $$\min_{x,s} f(x) - \mu \sum_{i=1}^m \log s_i$$
        $$\text{s.t. } c_E(x) = 0, \quad c_I(x) - s = 0$$
    *   **特点**: 通过逐步减小障碍参数$\mu \to 0$，子问题的解序列会收敛到原始问题的解。内点法在求解大规模线性、二次和非线性规划问题上都取得了巨大成功，是目前最强大的算法类别之一。
    *   **相关章节**: Chapter 19

# 学习要点

-   **转化思想**: 理解不同算法类别如何将复杂的约束问题转化为一系列更易于处理的子问题（无约束、QP、等式约束等）。
-   **核心子问题**: 掌握每个算法类别的核心子问题是什么。
    *   罚函数法 -> 无约束优化
    *   SQP -> 二次规划 (QP)
    *   内点法 -> 等式约束障碍问题
-   **适用场景**: 对各类算法的优缺点和适用范围有一个大致的了解。
    *   SQP: 对中小型问题非常高效，特别是当函数求值成本高时。
    *   内点法: 在大规模问题上通常比SQP更有优势。
    *   增广拉格朗日法: 实现相对简单，LANCELOT等软件基于此构建。

# 实践应用

-   **软件实现**: 现代优化软件包通常会实现上述一种或多种算法。例如，SNOPT是著名的SQP求解器，KNITRO和IPOPT是强大的内点法求解器，而LANCELOT和MINOS则是基于增广拉格朗日思想的求解器。
-   **问题选择**: 了解问题的特性（如规模、约束的线性/非线性程度、函数求值成本）有助于选择合适的算法类别和求解器。
