# 知识点概述

不等式约束二次规划（IQP）是二次规划的一般形式，包含线性的等式和不等式约束。求解IQP的核心挑战在于确定在解点哪些不等式约束是“积极的”（即取等号）。主要的求解算法分为两大类：积极集法（Active-Set Methods）和内点法（Interior-Point Methods）。积极集法通过迭代地维护一个“工作集”来猜测最优积极集，而内点法则通过追踪中心路径来逼近解，从而避免了对积极集的组合搜索。

# 教材原文

> The main challenge ... lies in determining which of these constraints are active at the solution and which are not. ... Active-set methods ... start by making a guess of the optimal active set ... solve a problem in which the constraints in the working set are imposed as equalities ... then check to see if ... the KKT conditions are satisfied. ... Interior-point methods ... generate iterates that stay away from the boundary of the feasible region defined by the inequality constraints.

# 详细解释

1.  **最优性条件**
    *   IQP的解$x^*$满足KKT条件(16.37)。对于凸QP（即Hessian矩阵$G$半正定），KKT条件是全局最优的充分条件。
    *   **退化 (Degeneracy)** 是一个关键的挑战，它可能发生在积极约束的梯度线性相关，或严格互补性不满足（即某个积极约束的乘子为0）时。退化会给算法（特别是积极集法）带来困难。

2.  **积极集法 (Active-Set Methods for Convex QP)**
    *   **思想**: 这是一个“组合”式的迭代方法。它维护一个当前迭代点的**工作集 (working set)** $\mathcal{W}_k$，作为对最优积极集的猜测。
    *   **算法框架 (Algorithm 16.3)**:
        1.  从一个可行点$x_k$和对应的工作集$\\mathcal{W}_k$开始。
        2.  **求解EQP子问题**: 固定工作集中的约束为等式，忽略其他不等式约束，求解一个等式约束QP子问题，得到搜索方向$p_k$。
            $$\min_p \frac{1}{2}p^T G p + g_k^T p \quad \text{s.t. } a_i^T p = 0, \forall i \in \mathcal{W}_k$$ 
        3.  **计算步长**: 沿着方向$p_k$前进，直到遇到第一个不在工作集中的约束的边界。步长$\alpha_k$在0和1之间取值。
        4.  **更新**: $x_{k+1} = x_k + \alpha_k p_k$。如果$\alpha_k < 1$，则将那个“挡住”前进的约束加入到新的工作集$\\mathcal{W}_{k+1}$中。
        5.  **检查最优性**: 如果某一步的$p_k=0$，说明当前点$x_k$是$\\mathcal{W}_k$子空间上的最优解。此时计算该EQP子问题的拉格朗日乘子$\hat{\lambda}_i$。
            *   如果所有对应不等式约束的$\hat{\lambda}_i \geq 0$，则KKT条件满足，算法找到最优解并终止。
            *   如果存在某个$\hat{\lambda}_j < 0$，则从工作集中**移除**约束$j$，然后开始下一次迭代。移除负乘子对应的约束可以保证目标函数能进一步下降。
    *   **特点**: 迭代点始终保持可行。工作集每次迭代通常只改变一个元素。对于严格凸QP，可以证明有限步收敛。

3.  **内点法 (Interior-Point Methods)**
    *   **思想**: 将不等式约束 $Ax \geq b$ 转化为等式约束和非负变量界限 $Ax-y=b, y \geq 0$。然后应用求解LP的原始-对偶内点法的思想。
    *   **KKT系统**: 构造一个包含障碍参数$\mu > 0$的扰动KKT系统：
        $$Gx - A^T\lambda + c = 0$$
        $$Ax - y - b = 0$$
        $$y_i \lambda_i = \mu, \quad i=1, \ldots, m$$
    *   **算法**: 通过牛顿法求解这个非线性系统来获得原始-对偶搜索方向$(\Delta x, \Delta y, \Delta \lambda)$，然后沿着该方向进行线搜索，同时保证$y, \lambda$严格为正。逐步减小$\mu \to 0$，迭代点序列会沿着中心路径收敛到解。
    *   **特点**: 迭代点在可行域的严格内部。每次迭代成本较高（需要求解一个大型线性系统），但通常迭代次数很少，并且对问题规模的增长不敏感。非常适合大规模QP。

# 学习要点

-   **核心挑战**: 理解求解IQP的关键在于正确识别最优积极集。
-   **积极集法 vs. 内点法**: 掌握两类算法的根本区别。
    *   **积极集法**: 在可行域的**边界**上移动，迭代地“猜测”积极集，每次迭代成本较低，但迭代次数可能很多。
    *   **内点法**: 在可行域的**内部**移动，通过追踪中心路径来逼近解，避免了组合搜索，每次迭代成本高，但迭代次数通常很少。
-   **算法选择**: 
    *   对于中小型问题，积极集法通常很有效。
    *   对于大规模问题，内点法通常更具优势。
    *   如果需要“热启动”（即从一个很好的初始猜测开始），积极集法通常能更快地收敛。

# 实践应用

-   **SQP方法**: IQP是序列二次规划（SQP）方法中IQP变体的核心子问题。
-   **投资组合优化**: 许多金融模型，如Markowitz模型，都是凸二次规划问题。
-   **模型预测控制 (MPC)**: 在控制领域，MPC的每一步都需要求解一个QP。
-   **支持向量机 (SVM)**: 在机器学习中，训练一个SVM分类器等价于求解一个QP。
