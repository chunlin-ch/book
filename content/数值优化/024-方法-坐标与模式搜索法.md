# 知识点概述

坐标搜索法和模式搜索法是两类简单直观的无导数优化方法。它们不构建显式的函数模型，而是通过在当前点周围沿着一组预先指定的方向进行“探索性移动”来寻找更好的点。如果探索成功，则移动到新点；如果失败，则缩小搜索范围（步长）。模式搜索法是坐标搜索法的一个推广，它对搜索方向集有更严格的要求，从而获得了更强的理论收敛保证。

# 教材原文

> Rather than constructing a model of $f$ explicitly based on function values, coordinate search and pattern-search methods look along certain specified directions from the current iterate for a point with a lower function value. If such a point is found, they step to it and repeat the process, possibly modifying the directions of search for the next iteration. If no satisfactory new point is found, the step length along the current search directions may be adjusted...

# 详细解释

1.  **坐标搜索法 (Coordinate Search Method)**
    *   **思想**: 最简单的模式搜索，轮流沿着每个坐标轴方向$e_1, e_2, 
i, e_n$进行一维搜索。
    *   **步骤**: 在第k次迭代中，固定除第k个分量外的所有变量，寻找$x_k$的最优值来降低目标函数。依次对所有分量进行一维最小化，完成一个循环。
    *   **缺点**: 
        *   **收敛性差**: 即使采用精确线搜索，也可能收敛不到驻点。当目标函数的等值线是狭长的椭圆且坐标轴不与之对齐时，算法会表现出非常缓慢的“之”字形行为（zigzagging）。
        *   **理论保证弱**: 搜索方向集$\{e_i, -e_i\}$不能保证总能找到下降方向，因为负梯度方向可能与所有坐标轴都近乎正交。

2.  **模式搜索法 (Pattern-Search Methods)**
    *   **思想**: 坐标搜索法的一个推广，它使用一个更丰富的“模式”或“框架”来进行探索。
    *   **算法框架 (Algorithm 9.2)**:
        1.  **定义模式**: 在当前点$x_k$，定义一个搜索方向集 $\mathcal{D}_k$ 和一个步长 $\gamma_k$。
        2.  **探索移动**: 检查“框架”中的点 $\{x_k + \gamma_k p \mid p \in \mathcal{D}_k\}$。
        3.  **成功**: 如果找到一个点 $x_k + \gamma_k p_k$ 使得函数值充分下降（例如 $f(x_k + \gamma_k p_k) < f(x_k) - \rho(\gamma_k)$），则接受该点为新迭代点 $x_{k+1}$，并可能扩大步长 $\gamma_{k+1} \geq \gamma_k$。
        4.  **失败**: 如果框架中所有点都没有带来充分下降，则不移动迭代点（$x_{k+1}=x_k$），并缩小步长 $\gamma_{k+1} < \gamma_k$。
    *   **对搜索方向集 $\mathcal{D}_k$ 的要求**: 为了保证全局收敛，$\mathcal{D}_k$必须满足关键条件：它所能张成的方向锥必须足够“广”，能够与任何可能的负梯度方向形成一个小于90度的夹角。这个性质由一个称为$\kappa(\mathcal{D}_k)$的度量来保证，要求$\kappa(\mathcal{D}_k) \geq \delta > 0$。常用的满足此条件的方向集包括：
        *   **坐标方向集**: $\{\pm e_1, \pm e_2, 
i, \pm e_n\}$。
        *   **单纯形方向集**: 由一个n维单纯形的顶点生成的$n+1$个方向。

# 学习要点

-   **基本机制**: 理解“探索-移动-调整步长”这一核心循环。
-   **坐标搜索的局限性**: 明白为什么简单的坐标轴搜索在理论上和实践中都可能效率低下。
-   **模式搜索的关键**: 掌握模式搜索法成功的关键在于其搜索方向集$\mathcal{D}_k$的设计，必须保证这些方向能“正向生成”整个空间，从而确保总能找到一个下降方向。
-   **收敛性**: 模式搜索法在适当的条件下（主要是对$\mathcal{D}_k$的要求），可以证明其梯度范数的一个子序列收敛到零（$\liminf \|
abla f_k\|=0$），具有比坐标搜索法更强的理论保证。

# 实践应用

-   模式搜索法由于其简单性和不需要导数的特性，在工程领域得到应用，特别是当函数评估成本不高时。
-   Hooke-Jeeves方法是早期一个著名的模式搜索算法，它结合了探索性移动和基于之前成功方向的“模式移动”。
-   现代的模式搜索算法，如广义模式搜索（GPS）和生成集搜索（GSS），有更强的理论基础和更复杂的方向与步长管理机制。
-   相比于基于模型的DFO方法，模式搜索法通常需要更多的函数求值次数才能达到相似的精度，尤其是在问题维度增加时。
