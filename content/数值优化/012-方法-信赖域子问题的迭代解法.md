# 知识点概述

对于中小型问题，可以通过迭代方法更精确地求解信赖域子问题，从而更充分地利用模型的二阶信息。这种方法的核心是利用最优性条件（Theorem 4.1），将子问题转化为一个关于拉格朗日乘子$\lambda$的一维求根问题。通过对方程进行巧妙的变换，可以使用牛顿法高效地找到最优的$\lambda$值，进而求得子问题的解。

# 教材原文

> The characterization of Theorem 4.1 suggests an algorithm for finding the solution $p$ of (4.7). Either $\lambda = 0$ satisfies (4.8a) and (4.8c) with $\|p\| \leq \Delta$, or else we define
> $$p(\lambda) = -(B+\lambda I)^{-1}g$$
> for $\lambda$ sufficiently large that $B+\lambda I$ is positive definite and seek a value $\lambda > 0$ such that
> $$\|p(\lambda)\| = \Delta. \tag{4.37}$$
> This problem is a one-dimensional root-finding problem in the variable $\lambda$.

# 详细解释

1.  **理论基础 (Theorem 4.1)**
    *   信赖域子问题的解$p^*$满足 $(B+\lambda I)p^* = -g$，其中$\lambda \geq 0$是一个拉格朗日乘子。
    *   并且满足互补条件 $\lambda(\Delta - \|p^*\|) = 0$。
    *   这意味着：如果解在信赖域内部（$\|p^*\| < \Delta$），则$\lambda=0$，步长就是模型的无约束最优解 $p^* = -B^{-1}g$（此时B必须半正定）。如果解在信赖域边界上（$\|p^*\| = \Delta$），则$\lambda \geq 0$。

2.  **一维求根问题**
    *   我们的目标是找到一个$\lambda \geq 0$，使得对应的步长$p(\lambda)$满足信赖域边界条件 $\|p(\lambda)\| = \Delta$。
    *   直接对函数 $\phi_1(\lambda) = \|p(\lambda)\| - \Delta = 0$ 应用牛顿法效果不佳，因为当$\lambda$接近$-B$的最小特征值时，该函数高度非线性。
    *   一个更好的策略是求解等价的方程 $\phi_2(\lambda) = \frac{1}{\Delta} - \frac{1}{\|p(\lambda)\|} = 0$。这个函数在解附近接近线性，因此牛顿法表现很好。

3.  **求解算法 (Algorithm 4.3)**
    *   这是一个应用于求解$\phi_2(\lambda)=0$的牛顿法迭代过程。
    *   **迭代步骤** (在第$\ell$次迭代):
        1.  给定当前的$\lambda^{(\ell)}$，尝试对矩阵 $B+\lambda^{(\ell)}I$ 进行Cholesky分解。
        2.  如果分解成功（即矩阵正定），则求解线性方程组 $(B+\lambda^{(\ell)}I)p_\ell = -g$ 得到步长$p_\ell$。
        3.  利用$p_\ell$和另一个辅助向量$q_\ell$（通过求解 $R^T q_\ell = p_\ell$ 得到，其中$R$是Cholesky因子），计算牛顿更新步，得到新的$\lambda^{(\ell+1)}$：
            $$\lambda^{(\ell+1)} = \lambda^{(\ell)} + \left(\frac{\|p_\ell\|}{\|q_\ell\|}\right)^2 \left(\frac{\|p_\ell\| - \Delta}{\Delta}\right)$$
    *   实际算法需要加入保护措施，例如当$B+\lambda^{(\ell)}I$非正定时，需要调整$\lambda^{(\ell)}$。

4.  **困难情况 (The Hard Case)**
    *   当梯度$g$与对应$B$最小特征值$\lambda_1$的特征子空间正交时，可能会出现对于所有$\lambda > -\lambda_1$都有$\|p(\lambda)\| < \Delta$的情况。此时，无法通过求解$\phi_2(\lambda)=0$找到解。
    *   根据Theorem 4.1，此时最优解对应的$\lambda$必定等于$-\lambda_1$。
    *   解$p$由两部分组成：一部分来自非奇异部分，另一部分来自$B+\lambda_1 I$的零空间（即$\lambda_1$对应的特征向量$z$）。即 $p = p_{\text{nonsingular}} + \tau z$。
    *   通过选择合适的$\tau$，可以使得最终的步长$p$满足边界条件$\|p\|=\Delta$。

# 学习要点

-   理解信赖域子问题的最优性条件是将其转化为关于$\lambda$的求根问题的关键。
-   掌握通过求解 $\frac{1}{\|p(\lambda)\|} = \frac{1}{\Delta}$ 而不是 $\|p(\lambda)\| = \Delta$ 来提高牛顿法效率的技巧。
-   了解“困难情况”的成因（梯度与最小特征向量正交）及其解决方法（在零空间中寻找一个分量）。
-   该迭代求解方法的计算成本主要在于每次迭代都需要进行一次矩阵分解（如Cholesky分解），因此通常只进行2-3次迭代来获得一个近似解。

# 实践应用

-   这种迭代求解方法是许多现代信赖域优化软件的核心部分，尤其适用于中等规模的问题，因为它能比近似方法（如狗腿法）更精确地利用模型的二阶信息。
-   在信赖域-牛顿法中，该方法可以直接应用于Hessian矩阵$\nabla^2 f(x_k)$，即使它是非正定的。算法会自动寻找一个$\lambda$使得$B_k+\lambda I$正定，从而自然地处理了负曲率问题。
