# 知识点概述

用于非线性规划（NLP）的内点法（或称障碍法）是将线性规划（LP）中极其成功的原始-对偶内点法思想推广到非线性领域的结果。其核心思想是通过引入对数障碍项来处理不等式约束，将原始的NLP问题转化为一系列的等式约束子问题。然后，通过对这些子问题的KKT系统应用牛顿法，并逐步将障碍参数$\mu$减小到零，来追踪一条通往最优解的中心路径。

# 教材原文

> Interior-point (or barrier) methods for nonlinear programming have been the subject of intensive research since the late 1980s. ... These methods are conceptually similar to the primal-dual interior-point methods for linear programming ...
> The basic idea is to solve the problem (19.1) by applying a barrier method to the inequality constraints. We can write the barrier subproblem as
> $$\min f(x) - \mu \sum_{i \in \mathcal{I}} \log s_i \quad \text{s.t. } c_E(x)=0, c_I(x)-s=0, \tag{19.3}$$
> where $\mu > 0$ is the barrier parameter.

# 详细解释

1.  **两种等价的视角**
    *   **障碍法视角**: 将不等式约束 $c_i(x) \geq 0$ 替换为 $c_i(x) - s_i = 0, s_i \geq 0$，然后对简单的非负约束 $s_i \geq 0$ 应用对数障碍函数。这得到了如公式(19.3)所示的等式约束障碍子问题。
    *   **原始-对偶KKT视角**: 直接写出原始NLP问题的KKT条件，然后像LP内点法一样，将互补松弛条件 $c_i(x) \lambda_i = 0$ (对于$i \in \mathcal{I}$) 扰动为 $c_i(x) \lambda_i = \mu$。这会得到一个与障碍子问题的KKT条件几乎完全相同的非线性方程组。

2.  **原始-对偶KKT系统**
    *   对障碍子问题(19.3)应用KKT条件，可以得到一个关于$(x, s, y, z)$的非线性系统（其中$y,z$是等式约束的乘子）。
    *   通过简化和变量替换（令$\lambda_i = \mu/s_i$），可以得到一个更紧凑的、与原始变量$(x, \lambda)$相关的原始-对偶系统：
        $$\nabla_x \mathcal{L}(x, \lambda) = 0$$
        $$c_E(x) = 0$$
        $$C_I(x) \Lambda_I e - \mu e = 0$$
        其中$C_I(x) = \text{diag}(c_i(x))$，$\Lambda_I = \text{diag}(\lambda_i)$。

3.  **内点法的核心步骤**
    *   **牛顿步**: 在当前迭代点$(x_k, \lambda_k)$，对上述原始-对偶系统应用牛顿法，求解一个大型的线性方程组来获得搜索方向$(\Delta x_k, \Delta \lambda_k)$。
        $$\begin{bmatrix} \nabla_{xx}^2 \mathcal{L}_k & -A_k^T \ A_k & 0 \end{bmatrix} \begin{bmatrix} \Delta x_k \ \Delta \lambda_k \end{bmatrix} = - \left[ \begin{array}{c} \nabla_x \mathcal{L}_k \ c_k \end{array} \right] \tag{19.12}$$
        （这是一个简化的形式，实际系统更复杂，包含了对角矩阵等项）
    *   **步长选择**: 沿着搜索方向进行线搜索，找到一个步长$\alpha_k$，使得迭代点保持在可行域内部（即$c_I(x) > 0, \lambda_I > 0$），并且价值函数得到充分下降。
    *   **障碍参数更新**: 在每次（或每几次）迭代后，减小障碍参数$\mu$，例如 $\mu_{k+1} = \sigma_k \mu_k$，其中$\sigma_k \in (0,1)$。

4.  **实用算法考量**
    *   **价值函数与线搜索**: 为了保证全局收敛，需要一个价值函数来决定步长。常用的价值函数是$\ell_1$罚函数，或者与障碍函数本身相关的函数。
    *   **Hessian近似**: 真实的拉格朗日Hessian矩阵$\nabla_{xx}^2 \mathcal{L}_k$可能非正定，导致牛顿步不是下降方向。实用算法需要修正这个Hessian（例如，通过加上一个正定矩阵）来保证KKT矩阵的惯性（inertia）正确，从而获得下降方向。
    *   **信赖域方法**: 也可以将内点法与信赖域框架结合。子问题是在信赖域内求解牛顿步方程，这可以更自然地处理Hessian的非正定性。
    *   **可行性恢复**: 如果线搜索失败（找不到满足条件的步长），算法需要进入一个可行性恢复阶段，其目标是找到一个能使价值函数下降的点。

# 学习要点

-   **与LP内点法的联系**: 理解NLP内点法是LP内点法思想的直接推广，核心都是“障碍项+中心路径+牛顿法”。
-   **障碍子问题**: 掌握通过引入对数障碍项将不等式约束问题转化为等式约束问题序列的核心技巧。
-   **KKT系统**: 了解NLP内点法的核心计算任务是反复求解一个大型的、对称不定的线性KKT系统。
-   **Hessian处理**: 认识到处理拉格朗-Hessian的非正定性是NLP内点法的一个关键挑战，与SQP方法类似。
-   **全局收敛**: 知道NLP内点法同样需要价值函数或过滤器等机制来保证全局收敛。

# 实践应用

-   内点法是求解大规模非线性规划问题的最强大和最可靠的算法之一，尤其适用于那些约束数量多、结构稀疏的问题。
-   **IPOPT**: 一个非常著名和广泛使用的开源NLP求解器，它是一个基于线搜索的内点法实现。
-   **KNITRO**: 一个商业求解器，提供了高性能的内点法和SQP法选项。
-   内点法在工程设计、经济建模、轨迹优化、模型预测控制等众多领域都有成功应用。
