# 知识点概述

无导数优化（Derivative-Free Optimization, DFO）是一类专门用于求解目标函数的导数信息不可用、不可靠或计算成本过高的问题的优化算法。与基于梯度的算法不同，DFO方法不试图计算或近似梯度/Hessian矩阵，而是直接利用函数在一些采样点处的值来决定下一步的迭代方向和位置。主要方法包括模型法、模式搜索法和单纯形法等。

# 教材原文

> Many practical applications require the optimization of functions whose derivatives are not available. ... various algorithms have been developed that do not attempt to approximate the gradient. Rather, they use the function values at a set of sample points to determine a new iterate by some other means.
> Derivative-free optimization (DFO) algorithms differ in the way they use the sampled function values to determine the new iterate. One class of methods constructs a linear or quadratic model of the objective function and defines the next iterate by seeking to minimize this model inside a trust region. ... Other widely used DFO methods include the simplex-reflection method of Nelder and Mead, pattern-search methods, conjugate-direction methods...

# 详细解释

1.  **适用场景**
    *   **黑箱函数**: 目标函数$f(x)$的计算过程是一个“黑箱”，例如来自一个复杂的计算机模拟或物理实验，其内部解析形式未知。
    *   **导数计算困难**: 即使函数解析式已知，但过于复杂，手动推导或使用自动微分工具都很困难。
    *   **带噪声的函数**: 函数值本身包含随机噪声（例如来自蒙特卡洛模拟），导致有限差分计算的梯度非常不可靠。

2.  **主要方法分类**
    *   **模型法 (Model-Based Methods)**:
        *   **思想**: 在当前点附近，通过对一组（例如$O(n^2)$个）采样点上的函数值进行**插值**，构建一个目标函数的近似模型（通常是二次或线性模型）。
        *   **步骤**: 在一个信赖域内最小化这个模型来产生一个试探步。然后根据试探步的实际效果来更新迭代点和信赖域。
        *   **特点**: 这是目前最有效的一类DFO方法，与信赖域方法紧密相关。它需要处理插值点的几何构型问题，以保证模型的质量。

    *   **模式搜索法 (Pattern-Search Methods)**:
        *   **思想**: 在当前点周围，沿着一组预先定义的“模式”向量（搜索方向）进行探索性移动。
        *   **步骤**: 在当前点$x_k$加上一个步长$\gamma_k$乘以每个模式向量，形成一个“框架”(frame)。如果找到了一个函数值更低的点，就移动到该点并可能增加步长；如果没有找到，则缩小步长，在原地进行更精细的搜索。
        *   **特点**: 理论上稳健，收敛性证明依赖于模式向量的设计，需要保证它们能“正向跨越”任何可能的下降方向。

    *   **Nelder-Mead 单纯形法 (Simplex-Reflection Method)**:
        *   **思想**: 维护一个由$n+1$个顶点构成的单纯形。在每次迭代中，试图通过反射、扩张、收缩等操作，用一个更好的点来替换函数值最差的顶点，从而使单纯形逐步“蠕动”并收缩到最小值点。
        *   **特点**: 非常流行，实现简单。但在某些情况下可能会停滞在非最优点，且收敛性理论不完善。

    *   **共轭方向法 (Conjugate-Direction Method)**:
        *   **思想**: 将线性共轭梯度法的思想推广到一般非线性函数，但完全不使用导数。它通过一系列沿着平行线的一维搜索来生成共轭方向。
        *   **特点**: 对于二次函数，它能在有限步内收敛。对于一般函数，它是一种启发式方法。

3.  **与有限差分法的对比**
    *   有限差分法通过非常近的采样点来**近似导数**，然后将此近似导数用于梯度类算法。这种方法对噪声敏感。
    *   DFO方法（特别是模型法）通常使用分布更广的采样点来**构建函数模型**，这在一定程度上对噪声更具鲁棒性。

# 学习要点

-   理解DFO问题的来源和挑战（导数不可用、噪声）。
-   掌握DFO的两大主流思想：基于模型的插值方法和基于方向探索的模式搜索方法。
-   了解Nelder-Mead方法的直观思想（反射、扩张、收缩单纯形）。
-   区分DFO方法与基于有限差分梯度近似的方法的根本不同。
-   认识到DFO算法通常只适用于中小型问题（例如$n$几十到几百），因为它们需要较多的函数求值次数来获取足够的信息。

# 实践应用

-   **工程设计优化**: 许多设计的性能需要通过运行昂贵的模拟软件（如CFD、有限元分析）来评估，这些软件通常不提供导数信息。
-   **实验参数校准**: 在科学实验中，需要调整仪器参数以使输出与理论或期望结果最匹配，每次参数调整都需要进行一次物理实验来获得函数值。
-   **超参数调优**: 在机器学习中，选择模型的超参数（如学习率、正则化系数）是一个DFO问题，因为损失函数关于超参数的导数通常是未知的。
