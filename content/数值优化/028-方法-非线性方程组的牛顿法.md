# 知识点概述

求解非线性方程组 $r(x)=0$ 的牛顿法，是通过在当前点$x_k$对函数$r(x)$进行线性化，然后求解这个线性模型的根来获得下一步的位移$p_k$。这个线性模型就是$r(x)$在$x_k$处的一阶泰勒展开。在解附近，如果Jacobian矩阵非奇异，牛顿法具有Q-二次收敛的快速特性，是求解非线性方程组最重要和最基础的方法。

# 教材原文

> Newton's method is derived ... with a linear model, one that involves function values and first derivatives of the functions $r_i(x)$ ... at the current iterate $x_k$. We ... define a linear model $M_k(p)$ of $r(x_k+p)$ by ... writing
> $$M_k(p) = r(x_k) + J(x_k)p. \tag{11.5}$$ 
> Newton's method, in its pure form, chooses the step $p_k$ to be the vector for which $M_k(p_k)=0$, that is, $p_k = -J(x_k)^{-1} r(x_k)$.

# 详细解释

1.  **线性模型与牛顿步**
    *   **思想**: 在当前点$x_k$，用一个线性函数 $M_k(p)$ 来近似非线性函数 $r(x_k+p)$。
    *   **模型**: $M_k(p) = r(x_k) + J(x_k)p$，其中$J(x_k)$是$r(x)$在$x_k$处的Jacobian矩阵。
    *   **牛顿步**: 通过求解线性方程组 $M_k(p_k)=0$ 来获得牛顿步$p_k$。这等价于求解**牛顿方程**: 
        $$J(x_k) p_k = -r(x_k) \tag{11.6}$$ 
    *   **迭代**: 新的迭代点为 $x_{k+1} = x_k + p_k$。

2.  **与无约束优化的关系**
    *   无约束优化的牛顿法可以看作是求解梯度方程 $
abla f(x) = 0$ 的一个特例。此时，残差函数$r(x)$就是梯度$
abla f(x)$，而Jacobian矩阵$J(x)$就是Hessian矩阵$
abla^2 f(x)$。

3.  **局部收敛性 (Theorem 11.2)**
    *   **前提**: 在解$x^*$处，Jacobian矩阵$J(x^*)$是非奇异的（即解是**非退化 (nondegenerate)**的），并且$J(x)$在$x^*$附近是Lipschitz连续的。
    *   **结论**: 如果初始点$x_0$足够接近$x^*$，那么牛顿法产生的序列$\{x_k\}$将 **Q-二次收敛** 到$x^*$。
        $$\|x_{k+1} - x^*\| = O(\|x_k - x^*\|^2)$$
    *   如果只假设$J(x)$是连续的，则收敛速度是**Q-超线性**的。

4.  **纯牛顿法的缺陷**
    *   **全局收敛性**: 如果初始点$x_0$远离解，纯牛ton法（步长恒为1）可能不收敛，甚至会发散或循环。
    *   **奇异Jacobian**: 如果在某次迭代中$J(x_k)$是奇异的，牛顿步$p_k$可能无定义。
    *   **计算成本**: 需要计算Jacobian矩阵并求解一个$n \times n$的线性方程组，对于大规模问题成本很高。

# 学习要点

-   **核心思想**: 掌握牛顿法通过“线性化再求根”来迭代求解非线性方程组的核心思想。
-   **牛顿方程**: 熟记 $J_k p_k = -r_k$ 这一关键方程。
-   **二次收敛**: 理解牛顿法在良好条件下（解非退化、初始点足够近）具有的标志性快速收敛性质。
-   **局限性**: 认识到纯牛顿法缺乏全局收敛保证，需要通过线搜索或信赖域等全局化策略来改进。

# 实践应用

-   纯牛顿法本身很少直接使用，但它是许多实用算法（如线搜索牛顿法、信赖域牛顿法）的基础。
-   在许多科学和工程计算中，求解非线性方程组是核心步骤，例如：
    *   电路模拟
    *   化学反应平衡计算
    *   机器人运动学逆解
    *   飞行器稳定性分析（如教材中的Example 11.1）
-   在约束优化中，求解KKT条件构成的非线性方程组是SQP方法和内点法的核心，牛顿法是求解这些系统的基础。
