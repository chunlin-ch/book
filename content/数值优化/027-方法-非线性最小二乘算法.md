# 知识点概述

非线性最小二乘算法是专门为求解目标函数为残差平方和形式的优化问题而设计的。这类算法通过利用问题梯度和Hessian矩阵的特殊结构，来获得比通用无约束优化算法更高的效率。最主要的算法包括高斯-牛顿（Gauss-Newton）法和列文伯格-马夸尔特（Levenberg-Marquardt, LM）法。

# 教材原文

> The gradient and Hessian of $f(x) = \frac{1}{2}\|r(x)\|^2$ can be expressed as follows:
> \begin{equation}
> \nabla f(x) = J(x)^T r(x) \tag{10.4}
> \end{equation}
> \begin{equation}
> \nabla^2 f(x) = J(x)^T J(x) + \sum_{j=1}^m r_j(x) \nabla^2 r_j(x) \tag{10.5}
> \end{equation}
> The simplest of these methods—the Gauss-Newton method—can be viewed as a modified Newton's method ... we use the approximation
> \begin{equation}
> \nabla^2 f_k \approx J_k^T J_k \tag{10.24}
> \end{equation}
> The Levenberg-Marquardt method can be obtained by using the same Hessian approximation, but replacing the line search with a trust-region strategy.

# 详细解释

核心思想是利用Hessian矩阵(10.5)的特殊结构。在许多情况下，第一项$J^T J$比第二项（包含二阶导数和残差$r_j$的部分）更重要。这在**小残差问题 (small-residual problems)** 中尤其如此，即当解$x^*$附近的残差$r_j(x^*)$非常小时，Hessian矩阵几乎就等于$J(x^*)^T J(x^*)$。

1.  **高斯-牛顿法 (Gauss-Newton Method)**
    *   **思想**: 这是一个线搜索方法。它在牛顿法的基础上，使用$J_k^T J_k$来近似完整的Hessian矩阵 $\nabla^2 f_k$。
    *   **步长计算**: 搜索方向$p_k^{\text{GN}}$通过求解一个线性方程组得到：
        $$(J_k^T J_k) p_k^{\text{GN}} = -J_k^T r_k \tag{10.23}$$ 
        这个方程等价于求解一个线性最小二乘子问题：
        $$\min_p \frac{1}{2}\|J_k p + r_k\|^2 \tag{10.26}$$ 
    *   **优点**:
        *   **节省计算**: 无需计算真实的二阶导数$\nabla^2 r_j$。
        *   **下降方向**: 只要$J_k$是列满秩的，$p_k^{\text{GN}}$就一定是$f$的下降方向。
        *   **快速收敛**: 对于小残差问题，该方法近似于牛顿法，因此收敛速度很快（接近二次）。
    *   **缺点**: 如果$J_k$是秩亏或病态的，$J_k^T J_k$会是奇异或病态的，导致步长$p_k^{\text{GN}}$过大且不可靠。对于大残差问题，收敛速度可能很慢。

2.  **列文伯格-马夸尔特法 (Levenberg-Marquardt, LM Method)**
    *   **思想**: 这是一个信赖域方法。它同样使用$J_k^T J_k$作为Hessian近似，但通过在信赖域内求解二次模型来增加稳健性。
    *   **子问题**: 在每次迭代中求解：
        $$\min_p \frac{1}{2}\|J_k p + r_k\|^2, \quad \text{subject to } \|p\| \leq \Delta_k \tag{10.31}$$ 
    *   **步长计算**: 子问题的解满足方程：
        $$(J_k^T J_k + \lambda I) p_k^{\text{LM}} = -J_k^T r_k \tag{10.33}$$ 
        其中$\lambda \geq 0$是一个由信赖域半径$\Delta_k$决定的正则化参数。当$\lambda$很小时，步长接近Gauss-Newton步；当$\lambda$很大时，步长接近于一个缩放的最速下降步，方向为$-J_k^T r_k$。
    *   **优点**: 
        *   **稳健性**: 即使$J_k$是秩亏的，正则化项$\lambda I$保证了线性系统的系数矩阵是可逆的，因此总能计算出一个合理的步长。
        *   **全局收敛**: 信赖域框架保证了算法的全局收敛性。
        *   **快速收敛**: 对于小残差问题，信赖域最终会变得足够大，使得LM步等同于Gauss-Newton步，从而实现快速收敛。

3.  **大残差问题 (Large-Residual Problems)**
    *   当解附近的残差$r_j(x^*)$很大时，Hessian矩阵中的第二项 $\sum r_j \nabla^2 r_j$ 不可忽略。此时，Gauss-Newton和LM方法的Hessian近似$J^T J$是不准确的。
    *   **结果**: 算法的收敛速度会退化为线性收敛。
    *   **解决方法**: 
        *   **混合算法**: 设计一种能在小残差时像Gauss-Newton一样，大残差时像拟牛顿法（如BFGS）一样的混合策略。
        *   **近似二阶项**: 使用拟牛顿法（如BFGS或SR1）来近似Hessian中的第二项，即维护一个矩阵$S_k$来近似 $\sum r_j \nabla^2 r_j$，然后用 $B_k = J_k^T J_k + S_k$ 作为Hessian近似。NL2SOL软件包就是基于这种思想。

# 学习要点

-   **核心近似**: 掌握Gauss-Newton和LM方法的核心思想，即用$J^T J$近似完整的Hessian矩阵。
-   **GN vs. LM**: 理解Gauss-Newton是线搜索方法，而Levenberg-Marquardt是信赖域方法。LM通过正则化参数$\lambda$（或信赖域半径$\Delta$）在Gauss-Newton步和最速下降步之间进行权衡，从而更稳健。
-   **小残差 vs. 大残差**: 明白问题的残差大小决定了$J^T J$近似的好坏，并直接影响算法的收敛速度。小残差问题收敛快，大残差问题收敛慢。
-   **子问题求解**: 了解Gauss-Newton和LM的子问题都可以转化为线性最小二乘问题来求解，可以使用QR分解等稳定方法。

# 实践应用

-   Levenberg-Marquardt法是求解非线性最小二乘问题的**标准和默认算法**，被广泛应用于各种科学和工程计算软件中（如MATLAB的`lsqnonlin`）。
-   在计算机视觉（如相机标定、三维重建）、机器人（如运动学逆解）、计量经济学等领域，非线性最小二乘算法是核心的计算工具。
