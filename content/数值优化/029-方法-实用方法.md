# 知识点概述

为了使牛顿法等局部算法具有全局收敛性（即从远离解的初始点也能收敛），必须引入全局化策略。对于非线性方程组求解，主要的实用方法是线搜索和信赖域。这两种策略都需要一个**价值函数 (Merit Function)** 来判断一个试探步是否“好”，即是否朝着解的方向取得了有意义的进展。

# 教材原文

> The Newton and Broyden methods ... cannot be guaranteed to converge to a solution of $r(x)=0$ unless they are started close to that solution. ... To make them more robust, we can use line-search and trust-region techniques similar to those described in Chapters 3 and 4. Before describing these techniques, we need to define a merit function, which is a scalar-valued function of $x$ that indicates whether a new iterate is better or worse than the current iterate, in the sense of making progress toward a root of $r$.

# 详细解释

1.  **价值函数 (Merit Functions)**
    *   **目的**: 提供一个标量标准来评估迭代步的质量。在无约束优化中，目标函数$f(x)$本身就是天然的价值函数。对于非线性方程组$r(x)=0$，我们需要构造一个函数，其全局最小值点对应于方程组的根。
    *   **最常用的价值函数**: **残差平方和**
        $$f(x) = \frac{1}{2}\|r(x)\|_2^2 = \frac{1}{2} \sum_{i=1}^n r_i^2(x) \tag{11.35}$$ 
    *   **性质**: 
        *   $f(x) \geq 0$，且当且仅当$r(x)=0$时，$f(x)=0$。因此，方程组的任何根都是$f(x)$的全局最小值点。
        *   **问题**: $f(x)$可能存在**非零局部最小值 (spurious local minima)**，这些点不是方程组的根（即$r(x) \neq 0$），但满足$
abla f(x)=0$。可以证明，这种情况只在$J(x)$奇异时才会发生。
    *   **其他价值函数**: $\ell_1$范数价值函数 $\|r(x)\|_1$ 也是一个选择。

2.  **线搜索方法 (Line Search Methods)**
    *   **思想**: 将求解非线性方程组的问题转化为一个对价值函数$f(x)=\frac{1}{2}\|r(x)\|^2$的无约束优化问题。
    *   **下降方向**: 牛顿步 $p_k = -J_k^{-1}r_k$ 对于价值函数$f(x)$是一个下降方向，因为：
        $$p_k^T \nabla f(x_k) = p_k^T (J_k^T r_k) = (-J_k^{-1}r_k)^T (J_k^T r_k) = -r_k^T (J_k^{-T} J_k^T) r_k = -\|r_k\|^2 < 0$$ 
    *   **算法**: 
        1.  计算牛顿方向$p_k$。
        2.  沿着$p_k$进行线搜索，寻找一个步长$\\alpha_k$，使得价值函数$f(x)$得到充分下降（例如，满足Wolfe或Armijo条件）。
        3.  更新迭代点 $x_{k+1} = x_k + \\alpha_k p_k$。
    *   **缺点**: 当Jacobian矩阵$J_k$病态或奇异时，牛顿步可能非常长且方向很差，导致线搜索效率低下，算法可能收敛到价值函数的非零局部最小值，而不是方程组的根（如Powell的例子所示）。

3.  **信赖域方法 (Trust-Region Methods)**
    *   **思想**: 同样是最小化价值函数$f(x)=\frac{1}{2}\|r(x)\|^2$，但采用信赖域框架。
    *   **模型**: 在当前点$x_k$，构建一个$f(x)$的二次模型。最直接的模型是基于$r(x)$的线性化，即 $r(x_k+p) \approx r_k + J_k p$，从而得到$f(x)$的模型：
        $$m_k(p) = \frac{1}{2}\|r_k + J_k p\|^2 = f(x_k) + p^T J_k^T r_k + \frac{1}{2} p^T J_k^T J_k p$$ 
        这正是**Gauss-Newton**模型。
    *   **子问题**: 求解信赖域子问题：
        $$\\min_p m_k(p), \quad \text{subject to } \|p\| \leq \Delta_k$$ 
    *   **优点**: 信赖域框架能很好地处理$J_k$奇异或病态的情况，总能产生一个合理的步长，因此比线搜索方法更稳健。这是求解非线性方程组的首选全局化策略。

# 学习要点

-   **全局化**: 理解纯牛顿法为何需要全局化策略（线搜索或信赖域）来保证从任意初始点收敛。
-   **价值函数**: 掌握价值函数（特别是残差平方和）在全局化策略中的核心作用——作为判断迭代步好坏的标尺。
-   **线搜索 vs. 信赖域**: 比较两种全局化策略在应用于非线性方程组求解时的优缺点。线搜索法更简单，但可能因Jacobian病态而失败；信赖域法更复杂，但更稳健。
-   **非零局部最小值**: 认识到基于价值函数的策略可能会收敛到价值函数的局部最小值，而不是方程组的根，这是这类方法的一个固有挑战。

# 实践应用

-   几乎所有用于求解非线性方程组的现代软件库（如MINPACK, SNES）都实现了带有线搜索或信赖域全局化策略的牛顿法或其变体。
-   信赖域-牛顿法（特别是采用狗腿法或CG-Steihaug法求解子问题）是求解中大型非线性方程组的标准和高效算法。
