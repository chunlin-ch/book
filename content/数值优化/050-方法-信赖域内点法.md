# 知识点概述

信赖域内点法是将信赖域全局化策略与内点（障碍）法相结合的一种算法。与线搜索内点法不同，它不依赖于价值函数来保证收敛，而是通过在信赖域内求解牛顿步方程来获得搜索方向。这种方法能更自然地处理拉格朗日Hessian矩阵的非正定性，并且在理论上和实践中都表现出很好的稳健性。

# 教材原文

> We now consider an interior-point method that uses a trust-region approach to promote global convergence. This method does not require the use of a merit function. Instead, the trust-region constraint helps to control the quality of the step and ensures that the algorithm takes a reasonable step even when the Hessian of the Lagrangian has the wrong inertia.

# 详细解释

1.  **动机**
    *   线搜索内点法需要一个价值函数来决定步长，但价值函数的选择和参数调整可能很复杂，并且可能遭遇Maratos效应。
    *   信赖域方法提供了一种替代的全局化策略，它不依赖价值函数，而是通过信赖域半径来控制步长的大小。
    *   信赖域框架能更直接地处理Hessian非正定性，这在内点法中是一个核心挑战。

2.  **子问题定义**
    *   算法的核心是在每次迭代中，近似求解一个在信赖域约束下的等式约束问题。这个子问题是对障碍子问题(19.3)的线性化。
    *   **原始-对偶步长**: 搜索方向$(\Delta x, \Delta s, \ldots)$通过求解一个类似于标准内点法的线性KKT系统来获得，但增加了信赖域约束 $|\|\Delta x\| \leq \Delta_k$。
    *   **简化处理**: 直接处理带信赖域约束的KKT系统很复杂。一个实用的方法是，先利用KKT系统中的线性关系消去$\Delta s$等变量，得到一个只关于$\Delta x$的方程，然后将信赖域约束只施加在$\Delta x$上。

3.  **Byrd-Omojokun 方法**
    *   这是一个求解信赖域内点法子问题的实用策略。
    *   **步骤**:
        1.  **计算法向步 (Normal Step) $p_n$**: 首先，求解一个只考虑满足线性化约束的步长分量。这个步长指向约束的边界，其目标是最小化线性化约束的违反度。
            $$\min \|A_k p + c_k\|^2 \quad \text{s.t. } \|p\| \leq \xi \Delta_k$$ 
            其中$\xi \in (0,1)$是一个常数。
        2.  **计算切向步 (Tangential Step) $p_t$**: 然后，在保持线性化约束不变的切向空间内，求解一个旨在最小化目标函数二次模型的步长分量。这个子问题是一个等式约束的信赖域问题。
            $$\min m_k(p_n+p_t) \quad \text{s.t. } A_k p_t = 0, \|p_n+p_t\| \leq \Delta_k$$ 
    *   **总步长**: 最终的步长是法向步和切向步的和：$\Delta x = p_n + p_t$。
    *   **优点**: 这种分解将一个复杂问题分解为两个相对更容易处理的子问题，并且能有效地平衡目标函数下降和约束满足。

4.  **步长接受与信赖域更新**
    *   步长计算出来后，需要进行一个**分数步长规则 (fraction-to-the-boundary rule)**，以保证新的迭代点$(x_k+\alpha \Delta x_k, s_k+\alpha \Delta s_k)$满足严格正定性 $s>0$。
    *   然后，通过计算一个**预测下降量与实际下降量的比值**来评估步长的质量。这里的“下降量”是相对于一个价值函数（例如$\ell_1$罚函数或障碍函数自身）而言的。
    *   根据这个比值，像标准的信赖域方法一样，更新信赖域半径$\Delta_k$。

# 学习要点

-   **全局化策略**: 理解信赖域是替代线搜索和价值函数来保证内点法全局收敛的一种重要机制。
-   **子问题求解**: 掌握Byrd-Omojokun方法的核心思想，即将步长分解为“法向步”（处理约束）和“切向步”（处理目标函数）。
-   **与线搜索内点法的对比**: 
    *   信赖域法不强制要求Hessian修正是正定的，它能利用负曲率信息来产生步长。
    *   信赖域法在处理价值函数可能遇到的困难（如Maratos效应）时可能更稳健。
-   **与SQP的联系**: Byrd-Omojokun的“法向步-切向步”思想与信赖域SQP方法中的处理方式非常相似，都体现了将约束和目标分离处理的思想。

# 实践应用

-   信赖域内点法是一种强大而稳健的算法，特别适用于那些Hessian矩阵可能非正定或病态的困难问题。
-   一些现代优化求解器（如KNITRO）提供了信赖域内点法的选项。
-   这种方法在需要高可靠性的工程和科学计算应用中很有价值。
