# 知识点概述

单纯形法是求解线性规划（Linear Programming, LP）问题的经典算法。其基本思想是在可行域（一个多胞体）的顶点之间进行迭代搜索。从一个顶点出发，沿着一条能降低目标函数值的边移动到相邻的顶点。重复此过程，直到找不到可以继续下降的边为止，此时即达到最优解。该方法保证在有限步内找到线性规划问题的全局最优解。

# 教材原文

> All iterates of the simplex method are basic feasible points for (13.1) and therefore vertices of the feasible polytope. Most steps consist of a move from one vertex to an adjacent one for which the basis $\mathcal{B}$ differs in exactly one component. On most steps (but not all), the value of the primal objective function $c^T x$ is decreased.

# 详细解释

对于标准形式的LP问题: $\min c^T x$, s.t. $Ax=b, x \geq 0$。

1.  **基本概念**
    *   **基本可行点 (Basic Feasible Point)**: 可行域的一个顶点。在代数上，它对应于将$n$个变量中的$n-m$个变量（非基变量）固定为0，然后求解剩余$m$个变量（基变量）得到的唯一解，并要求该解满足非负性。
    *   **基 (Basis)**: 对应于基变量的$m$个线性无关的列向量构成的矩阵$B$。

2.  **单纯形法的核心步骤 (Pivoting)**
    *   **思想**: 从一个基本可行点（顶点）出发，寻找一条边，沿着它移动到相邻的顶点可以使目标函数值下降最多（或最快）。
    *   **迭代过程 (Procedure 13.1)**:
        1.  **定价 (Pricing)**: 计算每个**非基变量**的**判别数 (reduced cost)** $s_j$。判别数表示当该非基变量$x_j$从0增加一个单位时，目标函数值的变化率。公式为 $s_N = c_N - N^T \lambda$，其中$\lambda$由 $B^T \lambda = c_B$ 求解得到。
        2.  **选择进基变量 (Entering Index)**: 检查所有判别数。如果所有$s_j \geq 0$，则当前解已是最优，算法终止。否则，选择一个判别数$s_q < 0$对应的变量$x_q$作为进基变量。有多种选择策略：
            *   **Dantzig法则**: 选择最负的$s_q$。
            *   **Steepest-Edge法则**: 选择使得目标函数下降最快的边。
        3.  **选择出基变量 (Leaving Index) / 比率测试 (Ratio Test)**: 增加进基变量$x_q$的值，同时调整基变量的值以维持$Ax=b$。$x_q$能增加的最大值，受限于某一个基变量$x_p$首先降低到0。这个$x_p$就成为出基变量。这个过程通过最小比率测试来完成。
        4.  **更新**: 用进基变量$q$替换出基变量$p$，形成新的基$\mathcal{B}$，更新基矩阵$B$及其分解，然后回到步骤1。

3.  **特殊情况**
    *   **无界问题 (Unboundedness)**: 如果在比率测试中，发现进基变量$x_q$可以无限增加而所有基变量都保持非负，则说明问题是无界的。
    *   **退化与循环 (Degeneracy and Cycling)**: 如果一个基本可行点中某个基变量的值为0，则称为**退化点**。在退化点进行迭代时，可能步长为0，目标函数值不下降。在极端情况下，算法可能在一系列退化点之间循环，永远无法终止。实际的单纯形法实现需要采用**反循环策略**，如扰动法或字典序法。

4.  **初始化：两阶段法 (Two-Phase Method)**
    *   **问题**: 单纯形法需要一个初始的基本可行点，但找到一个这样的点本身就不容易。
    *   **第一阶段 (Phase I)**: 构造一个辅助的LP问题，其目标是最小化人为引入的“人工变量”的和。这个辅助问题有一个平凡的初始基本可行点。求解该问题：
        *   如果辅助问题的最优值为0，则其最优解对应于原始问题的一个基本可行点，可以作为第二阶段的起点。
        *   如果辅助问题的最优值大于0，则说明原始问题无解（不可行）。
    *   **第二阶段 (Phase II)**: 从第一阶段找到的基本可行点开始，使用原始的目标函数求解原始的LP问题。

# 学习要点

-   **几何直观**: 将单纯形法理解为在可行多胞体的顶点上“爬山”（或“下山”）。
-   **代数核心**: 掌握基变量/非基变量的划分，以及如何通过求解线性方程组来计算判别数和更新方向。
-   **关键步骤**: 熟记“定价-选入-选出-更新”的完整枢轴操作流程。
-   **两阶段法**: 理解为何需要两阶段法，以及第一阶段如何帮助我们找到一个初始可行解或判断问题不可行。
-   **效率**: 尽管在最坏情况下单纯形法的复杂度是指数级的（Klee-Minty例子），但在实践中它通常非常高效。

# 实践应用

-   单纯形法是求解线性规划问题最著名和最广泛使用的方法之一，被集成在几乎所有的商业和开源优化求解器中（如CPLEX, Gurobi, GLPK）。
-   它在运筹学、经济学、管理科学、工程等领域有无数应用，例如生产调度、资源分配、网络流问题等。
-   由于其能够提供一个基本可行解（顶点解），在需要整数解的混合整数规划的求解算法（如分支定界法）中，单纯形法是求解其线性松弛问题的核心工具。
