# 知识点概述

非线性共轭梯度法是将线性共轭梯度法的思想推广到求解一般非线性无约束优化问题的一类算法。其核心优势在于每次迭代仅需要目标函数及其梯度信息，无需存储矩阵，因此非常适用于大规模问题。不同的非线性CG方法主要区别在于计算标量$\beta_k$的公式不同，其中最著名的是Fletcher-Reeves和Polak-Ribière方法。

# 教材原文

> Fletcher and Reeves showed how to extend the conjugate gradient method to nonlinear functions by making two simple changes in Algorithm 5.2. First, in place of the formula for the step length $\alpha_k$ ... we need to perform a line search that identifies an approximate minimum of the nonlinear function $f$ along $p_k$. Second, the residual $r$, which is simply the gradient of $\phi$ in Algorithm 5.2, must be replaced by the gradient of the nonlinear objective $f$.
> 
> **Fletcher-Reeves formula:**
> $$\beta_{k+1}^{\text{FR}} = \frac{\nabla f_{k+1}^T \nabla f_{k+1}}{\nabla f_k^T \nabla f_k} \tag{5.41a}$$
> 
> **Polak-Ribière formula:**
> $$\beta_{k+1}^{\text{PR}} = \frac{\nabla f_{k+1}^T (\nabla f_{k+1} - \nabla f_k)}{\|\nabla f_k\|^2} \tag{5.44}$$

# 详细解释

1.  **基本思想与算法框架**
    *   **推广**: 将求解二次函数最小化推广到求解一般非线性函数$f(x)$最小化。
    *   **改动**: 
        1.  用非线性函数梯度$\nabla f_k$替代线性CG中的残差$r_k$。
        2.  用非精确线搜索（如满足Wolfe条件的线搜索）替代计算$\alpha_k$的精确公式。
    *   **搜索方向**: 与线性CG类似，搜索方向由当前负梯度和上一步的搜索方向线性组合而成：
        $$p_k = -\nabla f_k + \beta_k p_{k-1} \quad (\text{with } p_0 = -\nabla f_0)$$

2.  **不同的 $\beta_k$ 公式**
    *   **Fletcher-Reeves (FR) 方法**: 
        公式如上(5.41a)。这是对线性CG中$\beta_k$公式最直接的推广。在强Wolfe线搜索条件下，可以证明其全局收敛性。
    *   **Polak-Ribière (PR) 方法**: 
        公式如上(5.44)。当目标函数是二次函数且采用精确线搜索时，PR公式与FR公式等价。但在一般非线性情况下，两者表现差异很大。
    *   **Hestenes-Stiefel (HS) 方法**: 
        $$\beta_{k+1}^{\text{HS}} = \frac{\nabla f_{k+1}^T (\nabla f_{k+1} - \nabla f_k)}{(\nabla f_{k+1} - \nabla f_k)^T p_k}$$
        在二次精确线搜索条件下也与FR等价，实际表现与PR类似。
    *   **比较与选择**: 
        *   **FR方法**: 具有较好的理论收敛性保证。但在某些情况下，如果算法产生了一个不好的方向和很小的步长，可能会导致后续一系列迭代都很糟糕，收敛缓慢。因此，FR方法通常需要配合重启策略使用。
        *   **PR方法**: 数值实验表明，PR方法通常比FR方法更稳健、更高效。它具有一种内置的“重启”机制：当算法进展不佳时（例如步长很小，$\nabla f_{k+1} \approx \nabla f_k$），$\beta_{k+1}^{\text{PR}}$会趋近于0，使得下一步的搜索方向$p_{k+1}$近似于最速下降方向$-\nabla f_{k+1}$，从而“重启”了搜索过程。
        *   **PR+**: PR方法的一个变体，通过取 $\beta_{k+1}^+ = \max\{\beta_{k+1}^{\text{PR}}, 0\}$ 来保证搜索方向始终是下降方向，并具有更好的理论收敛性。

3.  **重启策略 (Restarts)**
    *   **动机**: 由于非线性CG方法失去了线性CG的二次终止性，其产生的方向可能不再严格满足共轭性。重启是通过周期性地将搜索方向重置为最速下降方向（即令$\beta_k=0$），来“忘记”历史信息，开始新的共轭方向序列生成。
    *   **策略**: 
        1.  **n步重启**: 每n次迭代重启一次。这可以保证n步二次收敛，但对于大规模问题（n很大）意义不大。
        2.  **梯度正交性检测**: 基于线性CG中残差（梯度）相互正交的性质。当连续两次的梯度不正交时，即 $\frac{|\nabla f_k^T \nabla f_{k-1}|}{\|\nabla f_k\|^2} \geq \nu$（例如$\nu=0.1$），则进行重启。这是实践中更常用的策略。

# 学习要点

-   掌握非线性CG方法的基本迭代公式，特别是搜索方向的构造。
-   区分并记住至少两种$\beta_k$的计算公式：Fletcher-Reeves (FR) 和 Polak-Ribière (PR)。
-   理解FR和PR方法的优缺点和行为差异，特别是PR方法的自动重启特性。
-   明白为何需要重启策略以及常见的重启时机（n步重启、梯度正交性检测）。
-   非线性CG方法必须配合满足特定条件（如强Wolfe条件）的线搜索才能保证生成的方向是下降方向和算法的全局收敛。

# 实践应用

-   非线性CG方法是求解大规模无约束优化问题的首选方法之一，因为它不需要存储Hessian矩阵或其近似，内存开销仅为几个n维向量。
-   它被广泛应用于机器学习（如训练神经网络）、图像处理和各种工程设计优化问题中。
-   在实际使用中，Polak-Ribière (PR) 或其变体 (PR+) 通常比 Fletcher-Reeves (FR) 表现更好。
