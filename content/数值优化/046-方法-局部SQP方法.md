# 知识点概述

序列二次规划（Sequential Quadratic Programming, SQP）是求解非线性约束优化问题最有效的方法之一。其核心思想是在每次迭代中，通过对拉格朗日函数进行二次近似、对约束进行线性近似，来构造一个二次规划（QP）子问题。这个QP子问题的解给出了一个指向原始问题解的搜索方向。在解附近，SQP方法可以看作是求解KKT条件的牛顿法，因此具有快速的局部收敛性质（超线性收敛）。

# 教材原文

> Sequential quadratic programming (SQP) methods ... model the NLP problem (18.1) at the current iterate $x_k$ by a quadratic programming subproblem, then use the solution of this subproblem to define a new iterate $x_{k+1}$.
> For the equality-constrained problem ... the QP subproblem is
> $$\min_p \frac{1}{2} p^T \nabla_{xx}^2 \mathcal{L}(x_k, \lambda_k) p + \nabla f_k^T p \quad \text{s.t. } A_k p + c_k = 0. \tag{18.11}$$
> The step $p_k$ is the solution of this subproblem, and the new iterate is $x_{k+1} = x_k + p_k$. The new multiplier estimate $\lambda_{k+1}$ is the vector of Lagrange multipliers for the QP subproblem (18.11).

# 详细解释

1.  **EQP子问题 (等式约束)**
    *   对于等式约束问题 $\min f(x)$ s.t. $c(x)=0$，SQP在当前点$(x_k, \lambda_k)$构造的QP子问题如公式(18.11)所示。
    *   **与牛顿法的关系**: 这个QP子问题的KKT条件是：
        $$\begin{bmatrix} \nabla_{xx}^2 \mathcal{L}_k & A_k^T \\ A_k & 0 \end{bmatrix} \begin{bmatrix} -p_k \\ \lambda_{k+1} \end{bmatrix} = \begin{bmatrix} \nabla f_k \\ c_k \end{bmatrix} \tag{18.13}$$
        这恰好是求解原始问题KKT条件 $\nabla_x \mathcal{L}(x,\lambda)=0, c(x)=0$ 的**牛顿法方程**。因此，局部SQP方法本质上是对KKT系统应用牛顿法。

2.  **IQP子问题 (不等式约束)**
    *   对于包含不等式约束的一般非线性问题，QP子问题相应地包含线性化的不等式约束：
        $$\min_p \frac{1}{2} p^T B_k p + \nabla f_k^T p$$
        $$\text{s.t. } \nabla c_i(x_k)^T p + c_i(x_k) = 0, \quad i \in \mathcal{E}$$
        $$\nabla c_i(x_k)^T p + c_i(x_k) \geq 0, \quad i \in \mathcal{I}$$
        其中$B_k$是拉格朗日Hessian矩阵 $\nabla_{xx}^2 \mathcal{L}(x_k, \lambda_k)$ 或其拟牛顿近似。

3.  **局部收敛性 (Theorem 18.1)**
    *   **前提**: 初始点$(x_0, \lambda_0)$足够接近满足二阶充分条件的最优解$(x^*, \lambda^*)$，且在QP子问题中使用的Hessian矩阵是真实的拉格朗日Hessian。
    *   **结论**: 纯SQP方法（步长为1）具有**Q-二次收敛**速度。
    *   如果使用拟牛顿法（如BFGS）来近似拉格朗日Hessian，则通常可以获得**Q-超线性收敛**。

4.  **Hessian近似 (拟牛顿SQP)**
    *   计算真实的拉格朗日Hessian矩阵可能成本很高。实用的SQP方法通常采用拟牛顿法来近似它。
    *   **BFGS更新**: 最常用的方法是BFGS更新。但与无约束优化不同，这里更新的是**拉格朗日Hessian**。为了保证更新矩阵的正定性（这对于QP子问题的求解很重要），需要满足曲率条件 $s_k^T y_k > 0$，其中$s_k=x_{k+1}-x_k$，$y_k = \nabla_x \mathcal{L}(x_{k+1}, \lambda_{k+1}) - \nabla_x \mathcal{L}(x_k, \lambda_{k+1})$。
    *   当曲率条件不满足时，可以跳过更新，或者采用**Damped BFGS**等修正策略。

# 学习要点

-   **核心思想**: 掌握SQP通过“二次模型+线性约束”来构造QP子问题的核心思想。
-   **与牛顿法的联系**: 深刻理解局部SQP方法等价于对KKT系统应用牛顿法，这是其快速局部收敛性的理论根源。
-   **QP子问题**: 熟记EQP和IQP子问题的标准形式。
-   **Hessian近似**: 了解为何需要以及如何使用拟牛顿法（特别是BFGS）来近似拉格朗日Hessian，以及由此带来的曲率条件问题。
-   **局部性**: 认识到本节讨论的SQP方法是**局部**的，它不包含全局化策略（如线搜索或信赖域），因此只有在足够接近解时才能保证收敛。

# 实践应用

-   局部SQP方法是所有实用SQP算法的基础。全局化的SQP算法（见[[047-方法-实用SQP方法]]）通过在线搜索或信赖域框架中嵌入这个QP子问题求解过程，来实现从任意初始点收敛。
-   由于其出色的效率和精度，SQP是求解中小型非线性规划问题的首选方法之一。
