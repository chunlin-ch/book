# 知识点概述

增广拉格朗日法（Augmented Lagrangian Method），又称乘子法（Method of Multipliers），是对二次罚函数法的一个重要改进。它通过在罚函数中引入拉格朗日乘子的显式估计，从而避免了罚参数$\mu$必须趋于无穷大才能获得精确解的问题。这极大地改善了子问题的病态性，使得算法在有限的罚参数下就能收敛到解，从而更加高效和稳健。

# 教材原文

> The augmented Lagrangian function $\mathcal{L}_A(x, \lambda; \mu)$ achieves this goal by including an explicit estimate of the Lagrange multipliers $\lambda$ ... in the objective. From the definition
> $$\mathcal{L}_A(x, \lambda; \mu) = f(x) - \sum_{i \in \mathcal{E}} \lambda_i c_i(x) + \frac{\mu}{2} \sum_{i \in \mathcal{E}} c_i^2(x), \tag{17.36}$$
> we see that the augmented Lagrangian ... is a combination of the Lagrangian function and the quadratic penalty function.
> This discussion motivates the following algorithmic framework.
> 1. Find an approximate minimizer $x_k$ of $\mathcal{L}_A(x, \lambda^k; \mu_k)$.
> 2. Update Lagrange multipliers using $\lambda_i^{k+1} = \lambda_i^k - \mu_k c_i(x_k)$.

# 详细解释

1.  **动机与函数定义**
    *   **动机**: 二次罚函数法的一个主要缺陷是，为了得到可行解，罚参数$\mu$必须趋于无穷，这导致子问题的Hessian矩阵高度病态。增广拉格朗日法的目标是，在$\mu$保持有限的情况下也能得到解。
    *   **函数定义 (等式约束)**: 如公式(17.36)所示，增广拉格朗日函数是在标准拉格朗日函数的基础上，增加了一个二次罚项。

2.  **算法框架 (Framework 17.3)**
    *   这是一个两层循环的结构：
        *   **内层循环**: 对于固定的乘子估计$\lambda^k$和罚参数$\mu_k$，近似求解一个无约束（或界约束）的子问题：
            $$\min_x \mathcal{L}_A(x, \lambda^k; \mu_k)$$
            得到解$x_k$。
        *   **外层循环**: 检查收敛性。如果不满足，则更新拉格朗日乘子和（可能）罚参数，然后进入下一个内层循环。

3.  **乘子更新法则**
    *   **核心思想**: 在子问题的解$x_k$处，我们有 $\nabla_x \mathcal{L}_A(x_k, \lambda^k; \mu_k) \approx 0$。展开此式可得：
        $$\nabla f(x_k) - \sum_i (\lambda_i^k - \mu_k c_i(x_k)) \nabla c_i(x_k) \approx 0$$
    *   对比原始问题的KKT条件 $\nabla f(x^*) - \sum_i \lambda_i^* \nabla c_i(x^*) = 0$，我们可以得到一个对最优乘子$\lambda^*$的估计：
        $$\lambda_i^* \approx \lambda_i^k - \mu_k c_i(x_k)$$
    *   这直接导出了**Hestenes-Powell乘子更新公式**: 
        $$\lambda^{k+1} = \lambda^k - \mu_k c(x_k) \tag{17.39}$$

4.  **理论性质 (Theorems 17.5 & 17.6)**
    *   **精确解的性质**: 如果我们能得到最优乘子$\lambda^*$，那么对于所有足够大的$\mu$，原始问题的解$x^*$就是$\mathcal{L}_A(x, \lambda^*; \mu)$的一个严格局部极小点。这意味着，与二次罚函数不同，我们不需要$\mu \to \infty$。
    *   **局部收敛性**: 当$\lambda^k$足够接近$\lambda^*$且$\mu_k$足够大时，子问题的解$x_k$会很接近$x^*$，并且更新后的乘子$\lambda^{k+1}$会比$\lambda^k$更接近$\lambda^*$。收敛速度与$1/\mu_k$成正比，因此可以通过增大$\mu_k$来加速收敛。

5.  **处理不等式约束的实用方法**
    *   **界约束拉格朗日法 (Bound-Constrained Lagrangian, BCL)**: 
        *   **思想**: 将一般不等式约束$c_I(x) \geq 0$通过引入松弛变量$s \geq 0$转化为等式约束$c_I(x)-s=0$。然后，只将等式约束放入增广拉格朗日函数中，而将简单的界约束（如$s \geq 0$和原始的$l \leq x \leq u$）作为子问题的显式约束。
        *   **子问题**: $\min_x \mathcal{L}_A(x, \lambda; \mu)$ s.t. $l \leq x \leq u$。
        *   **应用**: 这是著名的大规模优化软件**LANCELOT**采用的方法。
    *   **线性约束拉格朗日法 (Linearly Constrained Lagrangian, LCL)**: 
        *   **思想**: 在每次迭代中，将非线性约束线性化，并将这些线性化约束作为子问题的硬约束。目标函数则由拉格朗日函数和约束非线性部分的惩罚项构成。
        *   **应用**: 这是著名优化软件**MINOS**采用的方法。

# 学习要点

-   **核心优势**: 理解增广拉格朗日法相对于二次罚函数法的最大优势——通过更新乘子来避免罚参数$\mu$必须趋于无穷，从而克服了病态性问题。
-   **乘子更新**: 掌握Hestenes-Powell乘子更新公式的推导和意义。
-   **两种视角**: 增广拉格朗日法既可以看作是罚函数法的一种改进，也可以看作是对偶方法的一种形式。
-   **实用框架**: 了解BCL和LCL两种将理论转化为实用算法的主流思路，即将复杂约束放入目标函数，将简单约束作为子问题的显式约束。

# 实践应用

-   增广拉格朗日法是求解大规模非线性规划问题的最重要和最成功的算法类别之一。
-   **LANCELOT** 和 **MINOS** 是两个基于此思想的著名软件包，被广泛应用于科学和工程领域。
-   该方法对于等式约束和只有少量不等式约束的问题特别有效。
