# 知识点概述

无约束优化算法是迭代的，从一个初始点$x_0$开始，生成一个点序列{x_k}，希望能收敛到一个解。从当前点$x_k$移动到下一个点$x_{k+1}$的基本策略主要有两种：线搜索（Line Search）和信赖域（Trust Region）。

# 教材原文

> There are two fundamental strategies for moving from the current point $x_k$ to a new iterate $x_{k+1}$. Most of the algorithms described in this book follow one of these approaches.
> 
> In the **line search strategy**, the algorithm chooses a direction $p_k$ and searches along this direction from the current iterate $x_k$ for a new iterate with a lower function value.
> 
> In the second algorithmic strategy, known as **trust region**, the information gathered about $f$ is used to construct a model function $m_k$ whose behavior near the current point $x_k$ is similar to that of the actual objective function $f$. Because the model $m_k$ may not be a good approximation of $f$ when $x$ is far from $x_k$, we restrict the search for a minimizer of $m_k$ to some region around $x_k$.

# 详细解释

所有无约束优化算法都是迭代过程，其核心在于如何从当前点$x_k$确定下一个点$x_{k+1}$，以期$f(x_{k+1}) < f(x_k)$。

1.  **线搜索策略 (Line Search Strategy)**
    *   **核心思想**: “先选方向，再定步长”。
    *   **步骤**:
        1.  在当前点$x_k$选择一个**下降方向** $p_k$ (即满足 $p_k^T 
abla f_k < 0$ 的方向)。
        2.  沿着方向$p_k$进行一维搜索，找到一个合适的**步长** $\alpha_k > 0$。
        3.  更新迭代点: $x_{k+1} = x_k + \alpha_k p_k$。
    *   **关键问题**: 如何选择方向$p_k$和步长$\alpha_k$？
        *   **方向选择**: 最速下降方向 ($- \nabla f_k$)、牛顿方向 ($- (\nabla^2 f_k)^{-1} \nabla f_k$)、拟牛顿方向、共轭梯度方向等。
        *   **步长选择**: 精确线搜索（找到一维最优解）成本高，通常采用非精确线搜索，如满足Wolfe条件或Armijo回溯准则。

2.  **信赖域策略 (Trust-Region Strategy)**
    *   **核心思想**: “先定范围，再找目标”。
    *   **步骤**:
        1.  在当前点$x_k$附近构建一个目标函数$f$的**模型** $m_k$ (通常是二次模型)。
        2.  定义一个以$x_k$为中心的**信赖域**（通常是半径为$\Delta_k$的球），我们相信模型$m_k$在该区域内能很好地近似$f$。
        3.  求解信赖域子问题：在信赖域内寻找模型$m_k$的最小化点，得到候选步长$p_k$。
        4.  评估步长$p_k$的质量：通过比较模型下降量和实际函数下降量来判断模型的好坏。如果步长可接受，则移动到$x_k+p_k$并可能扩大信赖域；否则，保持在$x_k$并缩小信赖域。
    *   **关键问题**: 如何构建模型$m_k$和如何调整信赖域半径$\Delta_k$？
        *   **模型构建**: 通常采用泰勒展开的前几项，例如 $m_k(p) = f_k + \nabla f_k^T p + \frac{1}{2} p^T B_k p$，其中$B_k$可以是Hessian矩阵或其近似。
        *   **半径调整**: 基于模型预测的准确性。预测好则扩大半径，预测差则缩小半径。

# 学习要点

-   理解线搜索和信赖域两种策略的根本区别：线搜索是“方向+步长”，信赖域是“模型+范围”。
-   线搜索方法的核心是保证每一步都是下降方向，并找到合适的步长。
-   信赖域方法的核心是构建一个局部近似模型，并在信任的范围内求解该模型。
-   两种策略都旨在利用函数在当前点的局部信息（函数值、梯度、Hessian）来指导下一步的移动。

# 实践应用

-   **线搜索方法**: 实现相对简单，广泛应用于各种优化算法中，如最速下降法、共轭梯度法和大多数拟牛顿法（如BFGS）。
-   **信赖域方法**: 在处理Hessian矩阵非正定的情况时更为稳健，是牛顿法的一种重要全局化策略。许多现代优化软件（如KNITRO, LANCELOT）都提供了信赖域选项。
