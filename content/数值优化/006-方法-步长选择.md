# 知识点概述

在线搜索方法中，步长($\alpha_k$)的选择至关重要。理想的步长是1维函数 $\phi(\alpha) = f(x_k + \alpha p_k)$ 的全局最小值，但这在计算上过于昂贵。因此，实际算法采用非精确线搜索策略，寻找一个能提供足够函数下降量且计算成本低的步长。常用的准则包括Wolfe条件、Goldstein条件和简单的回溯（Backtracking）法。

# 教材原文

> A popular inexact line search condition stipulates that $\alpha_k$ should first of all give sufficient decrease in the objective function $f$, as measured by the following inequality:
> $$f(x_k + \alpha p_k) \leq f(x_k) + c_1 \alpha \nabla f_k^T p_k, \quad c_1 \in (0,1) \tag{3.4}$$ 
> To rule out unacceptably short steps we introduce a second requirement, called the curvature condition, which requires $\alpha_k$ to satisfy
> $$\\nabla f(x_k + \alpha_k p_k)^T p_k \geq c_2 \nabla f_k^T p_k, \quad c_2 \in (c_1, 1) \tag{3.5}$$ 
> These two conditions are known collectively as the **Wolfe conditions**.

# 详细解释

1.  **Wolfe 条件**
    *   **动机**: 确保步长既能带来足够的函数值下降，又不会太短以至于进展缓慢。
    *   **条件**:
        1.  **充分下降条件 (Sufficient Decrease / Armijo Condition)**: 
            $$f(x_k + \alpha_k p_k) \leq f(x_k) + c_1 \alpha_k \nabla f_k^T p_k, \quad c_1 \in (0,1)$$
            这个条件要求函数值的下降量与步长和方向导数的乘积成正比，防止步长过大导致函数值上升或下降不足。
        2.  **曲率条件 (Curvature Condition)**:
            $$\\nabla f(x_k + \alpha_k p_k)^T p_k \geq c_2 \nabla f_k^T p_k, \quad c_2 \in (c_1, 1)$$
            这个条件要求新点的梯度在$p_k$方向上的投影（即一维函数$\phi'(\alpha_k)$）不能太负。如果它非常负，说明还有很大的下降空间，应该增加步长。这个条件防止步长过小。
    *   **强Wolfe条件 (Strong Wolfe Conditions)**: 将曲率条件修改为：
        $$|\\nabla f(x_k + \alpha_k p_k)^T p_k| \leq c_2 |\\nabla f_k^T p_k|$$
        这额外排除了那些$\phi'(\alpha_k)$过大的点，使得步长更接近一维搜索的驻点。

2.  **Goldstein 条件**
    *   **动机**: 与Wolfe条件类似，也是为了保证充分下降和防止步长过小。
    *   **条件**: 要求步长$\alpha_k$位于一个区间内，使得：
        $$f(x_k) + (1-c)\\alpha_k \nabla f_k^T p_k \leq f(x_k + \alpha_k p_k) \leq f(x_k) + c\\alpha_k \nabla f_k^T p_k, \quad 0 < c < 1/2$$
    *   **缺点**: 可能会排除掉所有的一维极小值点。

3.  **回溯线搜索 (Backtracking Line Search)**
    *   **动机**: 一种更简单的策略，只使用充分下降条件。
    *   **步骤**: 从一个初始步长（例如$\alpha=1$）开始，如果充分下降条件不满足，则按比例（例如乘以$\rho \in (0,1)$）缩减步长，直到满足条件为止。
    *   **优点**: 实现简单，对于牛顿法和拟牛顿法非常有效，因为这些方法产生的步长为1的试探步通常是可接受的。

# 学习要点

-   理解精确线搜索和非精确线搜索的区别和取舍。
-   掌握Wolfe条件中两个不等式的含义：充分下降保证“质”，曲率条件保证“量”。
-   了解强Wolfe条件如何通过限制梯度的绝对值来获得更好的步长。
-   知道回溯法是一种简单而有效的步长选择策略，尤其适用于牛顿类方法。

# 实践应用

-   **拟牛顿法 (Quasi-Newton Methods)**: 通常使用满足Wolfe条件的线搜索，这对于保证Hessian近似矩阵的正定性至关重要。
-   **牛顿法 (Newton's Method)**: 回溯法是首选，因为它简单且能充分利用牛顿步长的优良特性（当接近解时，步长为1的牛顿步是很好的选择）。
-   **共轭梯度法 (Conjugate Gradient Methods)**: 通常需要更精确的线搜索，满足强Wolfe条件，以保证算法的收敛性和性能。
