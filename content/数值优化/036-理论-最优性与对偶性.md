# 知识点概述

线性规划（LP）的最优性理论是围绕着KKT条件和对偶理论展开的。对于LP，KKT条件不仅是必要条件，也是充分条件，这意味着满足KKT条件的任何点都是全局最优解。每个线性规划问题（原始问题）都有一个与之紧密相关的对偶问题。对偶理论，特别是强对偶定理，揭示了原始问题和对偶问题解之间的深刻联系，即它们的最优目标函数值相等。这个性质是单纯形法和内点法等算法的理论基础。

# 教材原文

> The KKT conditions for (13.1) are that there exist vectors $\lambda$ and $s$ such that
> $$A^T \lambda + s = c, \tag{13.4a}$$ 
> $$Ax = b, \tag{13.4b}$$ 
> $$x \geq 0, \tag{13.4c}$$ 
> $$s \geq 0, \tag{13.4d}$$ 
> $$x_i s_i = 0, \quad i=1, \ldots, n. \tag{13.4e}$$ 
> The dual problem for (13.1) is
> $$\max b^T \lambda, \quad \text{subject to } A^T \lambda \leq c. \tag{13.7}$$ 
> **Theorem 13.1 (Strong Duality).**
> (i) If either problem (13.1) or (13.7) has a (finite) solution, then so does the other, and the objective values are equal.

# 详细解释

1.  **最优性条件 (KKT Conditions for LP)**
    *   对于标准形式的LP: $\min c^T x$, s.t. $Ax=b, x \geq 0$。
    *   KKT条件 (13.4) 包含五个部分：
        1.  **对偶可行性 (Dual Feasibility)**: $A^T \lambda + s = c$ (其中$s \geq 0$)
        2.  **原始可行性 (Primal Feasibility)**: $Ax=b$ 和 $x \geq 0$
        3.  **互补松弛性 (Complementarity)**: $x_i s_i = 0$ for all $i$ (或等价地 $x^T s = 0$)
    *   **充分性**: 由于LP是凸优化问题，KKT条件是**充分条件**。任何满足KKT条件的点$(x, \lambda, s)$中的$x$都是原始问题的全局最优解，$(\lambda, s)$都是对偶问题的全局最优解。

2.  **对偶问题 (The Dual Problem)**
    *   每个LP问题（原始问题）都有一个伴随的对偶问题。标准形式LP的对偶问题如(13.7)所示。
    *   **对称性**: 对偶问题的对偶是原始问题。
    *   **变量关系**: 原始问题的约束对应对偶问题的变量，原始问题的变量对应对偶问题的约束。

3.  **弱对偶性 (Weak Duality)**
    *   **内容**: 对于任何原始可行解$x$和任何对偶可行解$\lambda$，总有 $c^T x \geq b^T \lambda$。
    *   **意义**: 对偶问题的目标函数值为原始问题的目标函数值提供了一个下界。它们之间的差 $c^T x - b^T \lambda = x^T s$ 被称为**对偶间隙 (duality gap)**，它总是非负的。

4.  **强对偶性 (Strong Duality)**
    *   **内容**: 如果原始问题或对偶问题有一个存在有限最优解，那么另一个问题也必有有限最优解，并且它们的最优目标函数值**相等**。
    *   **推论**: 在最优点$(x^*, \lambda^*, s^*)$，对偶间隙为零，即 $c^T x^* = b^T \lambda^*$，这等价于互补松弛条件 $x^{*T}s^*=0$。
    *   **另一种可能性**: 如果一个问题是无界的，那么它的对偶问题一定是不可行的。

# 学习要点

-   **KKT的充分性**: 深刻理解对于LP（作为凸优化问题），KKT条件是充分的，这是与一般非线性规划的关键区别。
-   **互补松弛**: 这是核心中的核心。它意味着，如果一个原始变量$x_i^*$在最优解中是严格正的，那么对应的对偶松弛变量$s_i^*$必须为零（即第i个对偶约束$A_i^T \lambda \leq c_i$取等号）。反之亦然。
-   **强对偶**: 记住“无间隙”这一强大结论。它将原始问题和对偶问题的求解联系在一起，是许多算法（特别是内点法）的理论基础。
-   **敏感性分析**: 对偶变量（拉格朗日乘子）$\lambda_i$可以被解释为当原始约束的右端项$b_i$发生微小变化时，最优目标函数值的变化率。因此，$\lambda$也被称为**影子价格 (shadow prices)**。

# 实践应用

-   **算法设计**: 
    *   **单纯形法**: 通过维护原始可行性和互补性，逐步迭代直到满足对偶可行性（即所有判别数非负）。
    *   **对偶单纯形法**: 通过维护对偶可行性和互补性，逐步迭代直到满足原始可行性。
    *   **内点法**: 同时作用于原始和对偶变量，直接求解KKT系统，并逐步将对偶间隙（或互补性乘积）驱动到零。
-   **经济学解释**: 在资源分配问题中，对偶变量$\lambda_i$代表了第$i$种资源的边际价值。如果一种资源没有用完（对应的原始松弛变量大于0），那么它的影子价格（对偶变量）就为0。
-   **问题诊断**: 如果你的LP模型求解出来是无界的，那么检查一下其对偶问题是否是不可行的，这有助于你理解和修正模型。
