# 知识点概述

在求解非线性约束优化问题时，算法产生的迭代步常常需要在“降低目标函数”和“满足约束”这两个相互冲突的目标之间做出权衡。价值函数（Merit Function）和过滤器（Filter）是用于决定是否接受一个试探步的两种主要机制。价值函数将两个目标合并为一个单一的标量函数，而过滤器则以一种多目标优化的方式来处理这两个目标。

# 教材原文

> Suppose that an algorithm ... generates a step that reduces the objective function but increases the violation of the constraints. Should we accept this step? ... We must look for a way to balance the twin (often competing) goals of reducing the objective function and satisfying the constraints. Merit functions and filters are two approaches for achieving this balance.

# 详细解释

1.  **价值函数 (Merit Functions)**
    *   **思想**: 将原始的约束优化问题转化为一个单一的无约束优化问题（或一系列子问题）。通过最小化这个构造出来的价值函数，来同时驱动目标函数下降和约束满足。
    *   **常用的价值函数**: **$\\ell_1$ 精确罚函数 ($\\ell_1$ Exact Penalty Function)**
        $$\\phi_1(x; \\mu) = f(x) + \\mu h(x) = f(x) + \\mu \\left( \\sum_{i \\in \\mathcal{E}} |c_i(x)| + \\sum_{i \\in \\mathcal{I}} [c_i(x)]^- \\right) \\tag{15.24}$$ 
        其中 $h(x)$ 是一个衡量约束违反度的函数，$\\mu > 0$ 是**罚参数**，用于平衡目标函数和约束违反度的权重。
    *   **精确性 (Exactness)**: $\\ell_1$罚函数是“精确的”，意味着在某些条件下，只要罚参数$\\mu$足够大（大于所有拉格朗日乘子绝对值的最大值），原始约束问题的局部解就对应于罚函数$\\phi_1$的局部极小点。这使得我们原则上可以通过单次最小化$\\phi_1$来求解原问题。
    *   **缺点**: 它是**非光滑**的（在可行域边界处不可微），这给最小化过程带来了挑战。基于它的算法通常需要处理非光滑性，例如通过求解一系列二次规划子问题。
    *   **步长接受准则**: 在线搜索方法中，要求步长能使价值函数得到充分下降，例如满足Armijo条件：
        $$\\phi_1(x_k+\\alpha_k p_k; \\mu) \\leq \\phi_1(x_k; \\mu) + \\eta \\alpha_k D(\\phi_1(x_k; \\mu); p_k)$$
        其中$D(\\cdot)$是方向导数。

2.  **过滤器 (Filters)**
    *   **思想**: 避免了罚参数的选择困难，直接处理两个目标：最小化$f(x)$和最小化约束违反度$h(x)$。
    *   **机制**:
        1.  **过滤器**: 维护一个历史迭代点的列表，其中包含了所有“非支配”的$(h,f)$值对。一个点$(h_i, f_i)$支配另一个点$(h_j, f_j)$意味着$h_i \\leq h_j$且$f_i \\leq f_j$。
        2.  **步长接受准则**: 一个新的试探点$x^+$被接受，当且仅当它的$(h(x^+), f(x^+))$值对**不被过滤器中的任何一个点所支配**。
        3.  **几何意义**: 过滤器在$(h,f)$平面上定义了一个“禁区”（所有被支配的区域）。只要新点落在这个禁区之外，它就被认为是可接受的。
    *   **优点**: 
        *   避免了选择和调整罚参数$\\mu$的困难。
        *   在某些情况下，可以避免Maratos效应，接受那些虽然稍微增加了约束违反度但大幅降低了目标函数的“好”步长。
    *   **挑战**: 
        *   需要处理当迭代点非常接近可行域边界时，算法可能因为无法同时降低$f$和$h$而停滞的问题。
        *   当算法无法找到可接受的步长时，需要启动一个**可行性恢复阶段 (feasibility restoration phase)**，该阶段的目标是专门减小约束违反度$h(x)$。

# 学习要点

-   **核心冲突**: 理解约束优化中“目标下降”与“约束满足”之间的内在冲突。
-   **价值函数 vs. 过滤器**: 掌握两种全局化机制的根本区别。价值函数是**单目标**转化，将多目标问题变为单一标量函数的最小化；过滤器是**多目标**视角，直接处理两个目标，避免了参数权衡。
-   **$\\ell_1$罚函数**: 了解其形式、精确性的含义以及非光滑的特性。
-   **过滤器的支配规则**: 明白过滤器是如何通过“非支配”规则来决定步长是否可接受的。
-   **Maratos效应**: 知道这两种机制都可能遭遇Maratos效应，即拒绝一个实际上很好的、朝向解的步长，并需要额外的策略（如二阶校正）来修正。

# 实践应用

-   **SQP方法**: 现代SQP求解器中，线搜索版本通常使用$\\ell_1$或$\\ell_2$价值函数，而信赖域版本则更多地采用过滤器或$\\ell_1$罚函数模型。
-   **FILTERSQP**: 一个著名的求解器，其核心就是过滤器机制。
-   **SNOPT**: 一个广泛使用的求解器，它主要使用价值函数，但在某些情况下会进入“弹性模式”，这与罚函数的思想有关。
