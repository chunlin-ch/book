# 知识点概述

不精确牛顿法是牛顿法的一个重要变体，特别适用于大规模问题。其核心思想是在每次迭代中不精确地求解牛顿方程 $\nabla^2 f_k p_k = -\nabla f_k$，而是找到一个近似解$p_k$来作为搜索方向。通常使用共轭梯度（CG）等迭代方法来求解该线性方程组，并通过一个动态变化的容忍度来控制近似解的精度，从而在保证快速收敛的同时，显著降低了计算成本。

# 教材原文

> Most rules for terminating the iterative solver for (7.1) are based on the residual
> $$r_k = \nabla^2 f_k p_k + \nabla f_k, \tag{7.2}$$
> Usually, we terminate the CG iterations when
> |$$\|r_k\| \leq \eta_k \|\nabla f_k\|, \tag{7.3}$$
> where the sequence {\eta_k} (with $0 < \eta_k < 1$ for all $k$) is called the forcing sequence.

# 详细解释

1.  **动机**
    *   对于大规模问题，精确求解牛顿方程（需要对Hessian矩阵进行分解）的计算成本（$O(n^3)$）和内存成本（$O(n^2)$）都非常高，难以承受。
    *   不精确牛顿法通过迭代法（如CG）求解牛顿方程，避免了矩阵分解，并将主要计算成本降低为若干次Hessian-向量乘积。
    *   在远离解时，没有必要花费大量计算去获得一个非常精确的牛顿步，一个粗糙的近似解就足以引导算法取得进展。

2.  **不精确牛顿条件 (Inexact Newton Condition)**
    *   如公式(7.3)所示，不精确牛顿法用残差$r_k$的范数来衡量牛顿方程的求解精度。
    *   **强制序列 (Forcing Sequence)** {\eta_k} 的选择至关重要，它控制着求解的精度，并直接影响算法的收敛速度。

3.  **局部收敛性 (Theorems 7.1 and 7.2)**
    *   **Q-线性收敛**: 只要强制序列\eta_k 一致小于1（例如 \eta_k \leq \eta < 1$），算法就能在解的邻域内实现Q-线性收敛。
    *   **Q-超线性收敛**: 如果\eta_k \to 0$，算法可以实现Q-超线性收敛。
    *   **Q-二次收敛**: 如果Hessian矩阵是Lipschitz连续的，并且\eta_k = O(\|\nabla f_k\|)$，算法可以实现Q-二次收敛。
    *   **实用策略**: 一个实用的\eta_k 选择是 \eta_k = \min(0.5, \sqrt{\|\nabla f_k\|})$，这能保证超线性收敛；或者 \eta_k = \min(0.5, \|\nabla f_k\|)$，这能保证二次收敛。

4.  **与全局化策略的结合**
    *   **线搜索牛顿-CG法 (Line Search Newton-CG / Truncated Newton)**:
        *   在CG迭代求解牛顿方程的过程中，如果遇到负曲率方向（即 $d_j^T (\nabla^2 f_k) d_j \leq 0$），则CG迭代必须终止，并返回当前已计算出的步长。这保证了生成的方向$p_k$是下降方向。
        *   这种方法适用于大规模问题，特别是当Hessian-向量积可以通过有限差分或自动微分高效计算时（称为**Hessian-free**牛顿法）。
    *   **信赖域牛顿-CG法 (Trust-Region Newton-CG / CG-Steihaug)**:
        *   这是将不精确牛顿思想与信赖域框架结合的典范，也是目前最流行的大规模无约束优化方法之一。
        *   CG法被用来近似求解信赖域子问题。CG迭代从零向量开始，并在遇到负曲率方向或超出信赖域边界时终止。
        *   这种方法能很好地处理非正定Hessian，并且具有良好的全局收敛和快速局部收敛性质。

# 学习要点

-   理解不精确牛顿法的核心：用迭代法近似求解牛顿方程。
-   掌握不精确牛顿条件(7.3)和强制序列\eta_k 的概念。
-   了解\eta_k 的选择如何决定局部收敛速度（线性、超线性、二次）。
-   熟悉两种主要的全局化不精确牛顿法：线搜索牛顿-CG法和信赖域牛顿-CG法。
-   知道如何处理负曲率是不精确牛顿法（特别是线搜索版本）必须解决的关键问题。

# 实践应用

-   不精确牛顿法是求解大规模无约束优化问题的核心算法之一。
-   信赖域牛顿-CG法（如Steihaug算法）被广泛应用于各种优化软件中，用于求解无约束问题以及作为约束优化算法（如信赖域SQP和内点法）的子问题求解器。
-   Hessian-free的实现使得不精确牛顿法可以应用于那些Hessian矩阵巨大、稠密或者难以计算，但Hessian-向量积相对容易获得的问题。
